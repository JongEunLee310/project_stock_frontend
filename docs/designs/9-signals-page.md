# Design — Issue 9: Signals 시그널 페이지

> AI가 감지한 투자 검토 시그널을 **카드 그리드**로 보여주고, 신뢰도·근거를 확인해
> 판단 기록(`/decision-log`)으로 이어가게 한다. 데이터는 기존 `mockSignals`에서 파생한다
> (신규 도메인 타입 없음). 시안 충실화 재구현에서 신뢰도는 원형 링(SVG), 1개월 추이는
> `recharts` 스파크라인으로 표현한다(아래 "시안 충실화 재결정" 참조).

## 목적

상태·신뢰도·근거가 담긴 시그널을 한눈에 비교하고, 우선순위·최근 변경을 곁들여 빠르게
검토 대상을 고른 뒤, 카드에서 종목 리서치(`/research/:symbol`)·판단 기록(`/decision-log`)으로
이동한다.

## 화면 구성

라우트 `/signals`. 페이지 콘텐츠 영역(좌측 글로벌 내비게이션은 `AppShell` 소관, 범위 밖).

1. **페이지 헤더** — 제목 "시그널".
2. **요약 카드 4종** — 상태별 시그널 개수(파생 집계). 라벨 + 큰 값(개수).
   - 매수 검토 가능 / 위험 증가 / 추가 리서치 필요 / 관망 유지.
3. **필터 바** — 검색(종목/메시지), 상태 드롭다운, 시그널 유형(`SignalKind`) 드롭다운,
   정렬(신뢰도/우선순위/최근 변경), 필터 초기화.
4. **2단 레이아웃**:
   - **좌(메인)**: 시그널 카드 그리드.
   - **우(레일)**: 우선순위 패널 + 최근 변경된 시그널 패널.

## 컴포넌트 책임

| 요소 | 위치 | 책임 |
| --- | --- | --- |
| `SignalsPage` | `pages/ui` | mock 로드·필터/정렬/검색 상태 보유·하위 조합. 도메인 로직 최소화. |
| 요약 카드 그룹 | 페이지 내부 | 상태별 개수 파생 표시. 재사용 신호 약하면 페이지 내부. |
| 필터 바 | 페이지 내부 또는 `features` | 검색·상태·유형·정렬·초기화 제어. 상위 상태에 위임. |
| 시그널 카드 | 페이지 내부(재사용 시 `entities/signal` 후보) | 단일 시그널 표현(아래 카드 구조). |
| 우선순위 패널 | `widgets` 후보 | `priority` 오름차순 상위 시그널. |
| 최근 변경 패널 | `widgets` 후보 | `updatedAt` 내림차순 상위 시그널. |

### 시그널 카드 구조

| 영역 | 내용 |
| --- | --- |
| 헤더 | 종목 티커/이름(→ `/research/:symbol` Link) · 상태 `Badge`(StockStatus) · 시그널 유형 라벨 |
| 본문 | 시그널 메시지(`message`) |
| 신뢰도 | **원형 링 + 숫자**(`ConfidenceRing`, 인라인 SVG, `role="meter"`). 위험 증가=적색/그 외 emerald. (1차 설계의 CSS 막대바에서 시안 충실화로 변경) |
| 근거 | `reasons` bullet 리스트 |
| 갱신 | 마지막 갱신 시각(타임스탬프, 고정 `timeZone: 'Asia/Seoul'`) |
| 액션 | **[판단 기록]** 버튼(→ `/decision-log`), 보조로 리서치 보기(→ `/research/:symbol`) |

- 신뢰도 막대 채움 비율 = `confidence` %. 색상은 의미색 토큰 또는 기존 톤 재사용.
- 상태 Badge는 기존 `Badge`(StockStatus 매핑) 재사용 — 인라인 복제 금지.

### 우측 레일

- **우선순위 패널**: `priority` 오름차순 상위 N(티커 · 상태 · 신뢰도 요약). 항목 클릭 → 해당 카드/리서치.
- **최근 변경 패널**: `updatedAt` 내림차순 상위 N(티커 · 갱신 시각 · 상태).

## 결정 (2026-06-22 확정 → 시안 충실화로 일부 갱신)

- ~~**신뢰도 표시 = 막대바 + 숫자**(CSS 막대)~~ → **원형 링(SVG `ConfidenceRing`)**으로 갱신(아래 재결정 1).
- **요약 카드 = `mockSignals` 파생 집계**(상태별 개수) 유지. 시안 충실화로 "총 시그널" 카드를 추가해
  4종 → 5종(총 시그널 값·퍼센트는 정적 자리표시).
- **레이아웃 = 카드 그리드 + 우측 레일**(우선순위·최근 변경). watchlist는 테이블, signals는 그리드.

## Mock 보강 (신규 타입 없음)

현재 `mockSignals`는 3건이고 완료 조건의 **관망 유지** 상태가 빠져 있다. 그리드·요약·패널을
채우도록 항목을 보강한다(타입 변경 없이 항목만 추가):

- 최소 **관망 유지** 상태 시그널 1건 추가(완료 조건 충족).
- 그리드·우선순위·최근 변경이 의미 있게 보이도록 총 5~6건 수준으로 확장(다양한 `SignalKind`·신뢰도·
  `priority`·`updatedAt`). 기존 `satisfies Signal[]` 유지.

## Out of Scope

- 캔들·거래량 등 본격 분석 차트(이슈 19). 카드 1개월 추이 스파크라인은 시안 충실화 위해 도입(아래 재결정).
- 실시간 갱신·서버 연동·시그널 생성 로직(현 단계는 mock 표시).
- 신규 도메인 타입 신설(요약·우선순위·최근 변경 모두 기존 `Signal`/`mockSignals`에서 파생).

## 시안 충실화 재결정 (2026-06-22, 1차 구현 후 시안 재대조)

대시보드(PR #37)·관심 종목(PR #38)과 동일한 시안 충실화 기조로 시그널 페이지를 시안 대조 후 재구현했다.
사용자가 Codex와 직접 시안을 맞춘 의도적 변경이며, 기존 결정과 다음과 같이 달라진다.

1. **신뢰도 표시: CSS 막대바 → 원형 링(`ConfidenceRing`)**. 인라인 SVG 원형 진행 링(`role="meter"`,
   `aria-valuenow`)으로 카드 헤더 우측에 배치. 위험 증가 상태는 적색, 그 외 emerald. 차트 라이브러리가
   아닌 자체 SVG라 결정성 영향 없음.
2. **카드 1개월 추이 스파크라인 `recharts` 도입(이전 "스파크라인 = 이슈 19, 범위 밖" 뒤집음)**.
   각 카드 하단에 `LineChart` 스파크라인 + 1M 등락(±%). 폭은 `ResizeObserver`로 측정한 컨테이너 폭,
   `height` 고정·`isAnimationActive={false}`로 결정성 유지, `role="img"` + `aria-label`. 이슈 19 경계는
   캔들·거래량 등 본격 분석 차트 기준으로 재정의(대시보드/관심 종목 라운드와 동일).
3. **요약 카드 4종 → 5종**. 좌측에 "총 시그널" 카드 추가 + 상태별 4종. 모두 `mockSignals` 파생
   집계 — 총 시그널 = `signals.length`, 상태 카드 퍼센트 = `formatStatusShare`로 동적 계산(리뷰 반영으로
   하드코딩 `128건`·`42.2%` 등 제거). "알림 설정" 버튼은 `disabled` + "준비 중" 표기로 자리표시 명확화.
4. **비주얼 메타를 도메인 `Signal`로 이전**(리뷰 반영). 1차 구현은 `signalVisuals` 페이지 로컬 상수였으나,
   리뷰 Suggestion/Question을 반영해 `previousStatus`·`previousConfidence`·`oneMonthChangePercent`·
   `trendSeries`를 도메인 `Signal` 타입의 필수 필드로 승격(우선순위 델타·최근 변경 전이·스파크라인의 단일
   출처). `companyName`은 별도 보유하지 않고 `mockStocks`에서 파생(`stockNamesBySymbol`). `mockSignals`
   전 항목에 신규 필드 채움, `domain.test`에 멤버십·범위 검증 추가.
5. **우측 레일 충실화**. 우선순위/최근 변경 패널을 그리드 테이블형으로 재구성 — 우선순위는 신뢰도 델타
   (▲/▼ vs `previousConfidence`), 최근 변경은 `previousStatus → status` 전이를 표기.
6. **셸 톤 `cockpit-*` 토큰 적용**. 대시보드/관심 종목과 동일하게 페이지를 `cockpit-*` 토큰으로 통일.
7. **mock 확장(공유 영향 확인)**. `mockStocks` 6 → 8종(AMD/META 추가), `mockSignals`의 `sig-nvda-002`·
   `sig-tsla-002`를 `sig-amd-001`(AMD, 추가 리서치 필요)·`sig-meta-001`(META, 매수 검토 가능)로 교체.
   관심 종목 페이지는 전체 `mockStocks`를 표시하므로 8행이 되지만 푸터·페이지네이션이 동적이라 회귀 없음.
   대시보드는 `mockStocks.slice(0, 4)`라 무영향. 전체 테스트 통과로 회귀 없음 확인.

### 리뷰 반영 (Codex)

- **정적 자리표시 동적화**: 총 시그널 = `signals.length`, 상태 퍼센트 = `formatStatusShare` 계산.
  "전일 대비 +12건" → "현재 로드 기준", "알림 설정" 버튼 `disabled` + "준비 중" 표기.
- **비주얼 메타 도메인 이전**: `signalVisuals` 페이지 상수를 제거하고 `Signal` 도메인 필드로 승격(위 4 참조).

### 비차단 후속(이월)

- 원시 색(emerald/red/amber/blue/sky/orange, 신뢰도 링 색)의 의미 토큰화는 후속(대시보드/관심 종목과 동일 이월).
- 카드 스파크라인 폭 측정 방식이 관심 종목(고정 `width`)·시그널(`ResizeObserver` 측정)로 갈림 — 공통 스파크라인 추출 시 수렴 검토.
