헤더 밴드로, 박스는 AI 투자 스탠스 하나만 사용합니다.

## 3. 변경

헤더 밴드 구성 (xl 기준, 좌→우):

```text
[로고 이니셜 | 심볼+회사명 | 거래소·섹터]  [현재가(큰 숫자)+등락(색상 텍스트)]
[AI 투자 스탠스 박스: 라벨 + 스탠스 배지 + 신뢰도]  [지표 텍스트 그리드 2행×3열]
(우상단: 관심종목·워치리스트·판단 기록 버튼 — 유지, 크기 축소)
```

- `HeaderCard` — 현재가 블록의 타일 박스(border·bg)를 제거하고 큰 숫자 + 색상
  등락 텍스트로 표시한다.
- 지표 5종(시가총액·섹터·52주 범위·다음 실적 발표·평균 목표가)은 타일 카드를
  제거하고 `dt`(muted 라벨)/`dd`(값) 텍스트 그리드로 표시한다. 구분은 여백만
  사용하고 테두리·배경을 두지 않는다.
- AI 투자 스탠스 박스만 박스 형태를 유지한다: 라벨, 스탠스 배지, 신뢰도.
  `confidenceBasis`·`stanceComment`는 박스 안 xs muted 텍스트로 유지한다
  (필드 누락 금지).
- 액션 버튼 3종은 유지하되 `min-h-8 px-3 text-xs` 수준으로 축소해 헤더 우상단에
  배치한다.
- 지표 그리드가 2행×3열이 되며 마지막 열의 성장 비율은 `1.6fr`로 넓히되,
  최소 폭은 기존 `19rem`을 유지한다 (24rem으로 넓히면 viewport 1280~1316px
  구간에서 grid 최소 폭 합이 가용 폭을 초과해 가로 오버플로 발생 — PR #173
  리뷰 B1).

## 4. Risks / Notes

- 타일 제거로 다크 배경에서 값 대비가 약해질 수 있다. 값은 `font-semibold`
  이상, 라벨은 muted로 위계를 유지한다.
- 모바일(1열)에서는 기존과 같이 세로 스택으로 자연스럽게 떨어지는지 확인한다.
