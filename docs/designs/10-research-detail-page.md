# Design — Issue 10: Stock Research Detail 페이지

> 개별 종목의 가격·밸류에이션·뉴스·리스크·체크리스트·메모를 한 화면에서 검토하는 리서치 상세
> 페이지. 데이터는 기존 `mockStockResearch`(+헤더는 `mockStocks`)에서 파생한다(신규 도메인 타입
> 없음). 가격 추이는 차트 라이브러리 없이 **CSS/SVG 스파크라인**으로 표현한다(라인 차트 본격
> 구현은 이슈 19로 분리).

## 목적

`/research/:symbol`에서 종목 한 곳을 깊게 검토한다. AI 스탠스·브리핑으로 큰 그림을 잡고, 핵심
리스크·뉴스·촉매로 변수를 확인하며, 체크리스트·메모로 판단 과정을 남긴다. 모르는 심볼은
안전한 미발견 상태를 보여준다.

## 화면 구성

라우트 `/research/:symbol`. `useParams`로 심볼을 받아 대문자화 후 mock을 조회한다. 좌측 글로벌
내비게이션은 `AppShell` 소관(범위 밖).

1. **종목 헤더 카드** — 티커·이름·시장, 현재가·전일대비(`change`/`changePercent`), 상태 `Badge`,
   AI 스탠스(`stance`). 보조로 워치리스트(`/watchlist`)·판단 기록(`/decision-log`) 이동.
2. **가격 추이(스파크라인)** — `pricePoints`를 SVG `polyline` 미니 스파크라인으로 렌더. 최신 종가·
   기간 등락 텍스트 동반. 차트 라이브러리 미사용(이슈 19에서 본격 차트 치환).
3. **AI 브리핑 패널** — `briefing.headline` + `body`.
4. **2단 레이아웃**:
   - **좌(메인)**: 핵심 리스크 패널 → 뉴스·공시 요약 → 촉매 타임라인.
   - **우(레일)**: 의사결정 체크리스트(체크 가능) + 사용자 메모(입력 UI).

## 컴포넌트 책임

| 요소 | 위치 | 책임 |
| --- | --- | --- |
| `ResearchPage` | `pages/ui` | 심볼 파라미터 해석·mock 조회·미발견 처리·하위 조합·체크리스트/메모 로컬 상태 보유. |
| 헤더 카드 | 페이지 내부 | `mockStocks` 조인으로 종목 기본 정보·상태 Badge·스탠스 표시. |
| 스파크라인 | 페이지 내부(재사용 시 `shared/ui` 후보) | `pricePoints` → SVG polyline. 차트 라이브러리 미사용. |
| AI 브리핑 패널 | 페이지 내부 | `briefing` 표시. |
| 핵심 리스크 패널 | 페이지 내부(재사용 시 `entities` 후보) | `keyRisks`(3건+) 리스트, 위험도 `Badge`(RiskLevel). |
| 뉴스 요약 | 페이지 내부 | `news` 리스트(헤드라인·출처·시각·위험도). |
| 촉매 타임라인 | 페이지 내부 | `catalysts` 날짜 오름차순 타임라인. |
| 체크리스트 | 페이지 내부 | `checklist` 항목 체크박스(로컬 토글). |
| 메모 | 페이지 내부 | `memo` 초기값 textarea(로컬 입력). |

### 헤더 카드 구조

| 영역 | 내용 |
| --- | --- |
| 좌 | 티커·이름·시장(`mockStocks`), 현재가·전일대비 |
| 우 | 상태 `Badge`(StockStatus) · AI 스탠스(`stance`) |
| 액션 | 워치리스트(→ `/watchlist`) · 판단 기록(→ `/decision-log`) |

### 리스크/뉴스 위험도 표시

- `ResearchRisk.level`·`NewsItem.risk`는 `RiskLevel`(높음/중간/낮음) → 기존 `Badge` 재사용(인라인 복제 금지).

## 결정 (2026-06-22 확정)

- **가격 차트 = CSS/SVG 스파크라인**(차트 라이브러리 미사용). `pricePoints`를 polyline으로 그리고
  최신 종가·기간 등락 텍스트를 동반. 본격 라인 차트는 **이슈 19**로 분리(자리표시 단계 졸업).
- **데이터 = `mockStockResearch` 파생**(헤더는 `mockStocks` 조인). 신규 도메인 타입·필드 신설 안 함.
- **체크리스트·메모 = 로컬 상태**(`useState`). 현 단계는 mock 표시·상호작용까지이며 서버 영속화 없음
  (새로고침 시 초기화). 완료 조건의 "체크 가능"·"메모 입력 UI"를 충족.
- **레이아웃 = 헤더 + 스파크라인 + 브리핑 + 2단(메인 리스크/뉴스/촉매 · 우측 체크리스트/메모)**.
- **미발견 심볼** = mock에 없는 심볼은 안전한 미발견 안내(빈 상태) 표시.

## Out of Scope

- 본격 가격 차트·기술 지표 오버레이(이슈 19). 본 페이지는 스파크라인으로 충분.
- 실시간 시세·서버 연동·메모/체크리스트 영속화(현 단계 mock·로컬 상태).
- 신규 도메인 타입 신설(헤더·리스크·뉴스·촉매·체크리스트·메모 모두 기존 타입에서 파생).
- 다른 페이지·라우팅·네비게이션 변경.
