# Design — Issue 8: Watchlist 관심 종목 페이지

> 본 문서는 디자인 시안(`watchlist.png`)을 반영한 **목표 설계**다. PR #31(기본 테이블 버전)을
> 베이스라인으로 머지한 뒤, 이 설계를 **후속 보강 라운드**로 그 위에 구현한다.
> 차트(스파크라인·도넛·막대)는 **이슈 19**로 분리하고, 본 라운드는 레이아웃·컬럼·요약 카드·
> AI 관찰 레일의 **구조**를 우선한다(차트 자리에는 수치/플레이스홀더 표시).

## 시안 충실화 재결정 (2026-06-22, 1차 구현 후 시안 재대조)

1차 구현 후 시안과 대조해 다음 결정을 갱신한다(대시보드 라운드와 동일한 시안 충실화 기조).

- **미니 시각요소 = `recharts` 도입(이전 "이슈 19로 분리" 부분 뒤집음)**: 변화율 스파크라인은
  `LineChart`, 요약 카드의 막대/도넛은 `BarChart`/`PieChart`로 그린다. 시안의 미니 시각요소 톤을
  재현하면서 대시보드의 차트 구현 방식과 맞춘다. 컴팩트 차트는 테스트 환경 경고를 피하기 위해 명시적
  `width`/`height`를 사용하고, 종목 스파크라인 및 요약 차트는 `role="img"` + `aria-label`을 유지한다.
  (이슈 19 경계는 캔들·거래량 등 **본격 분석 차트** 기준으로 재정의 — 대시보드 라운드와 동일.)
- **테이블 = 공통 `Table` 미사용, 직접 `<table>` 구성(설계 의도 뒤집음)**: 즐겨찾기 토글 컬럼·행 케밥
  메뉴·행 전체 클릭/키보드 네비게이션·심볼별 로고 마크 등 시안의 행 인터랙션이 공통 `Table<T>`의 컬럼
  렌더 모델로는 표현이 어려워, 시안 충실도를 우선해 페이지 로컬 `<table>`로 직접 구성한다. 페이지네이션도
  시안 형태의 자리표시 컨트롤로 직접 구현(공통 `Table` pagination 미사용). → **공통 컴포넌트 재사용 원칙에서
  벗어나는 결정**이므로 후속에서 재사용 신호 확인 시 공통화 재검토(비범위·후속 참조).
- **정렬에 "사용자 설정" 키 추가**: 기본 정렬을 `custom`("사용자 설정", mock 원순서 유지)로 두고 변화율/
  현재가/심볼/마지막 갱신 키를 함께 제공. 이전 "다중 키·프리셋은 후속" 결정 중 단일 "사용자 설정" 옵션만
  선반영.
- **`mockStocks` 6종 확장(시안 행 수 충족)**: 기존 4종(NVDA/AAPL/TSLA/MSFT)에 AMZN/GOOGL 추가, `aiVerdict`를
  긴 영어 문장 → 짧은 한국어 라벨(위험 증가/안정/관망 유지 등)로, 등락·`changeSeries`·`lastUpdatedAt`을 시안
  값으로 갱신. **`mockStocks`는 대시보드와 공유** — 대시보드는 상위 4종을 쓰고 `dashboardStatusBySymbol`로
  상태를 오버라이드하므로 회귀 없음(테스트 58/58 유지). 셸·페이지는 `cockpit-*` 토큰 사용(대시보드 라운드와 정합).

## 목적

관심 종목의 상태·변화율·뉴스 위험도·밸류에이션·테마 과열·AI 판단을 한 테이블에서 비교하고,
요약 KPI와 AI 관찰(메모·최근 추가·알림 설정)을 곁들여 빠르게 판단하며, 종목에서 리서치 상세
(`/research/:symbol`)로 이동한다.

## 화면 구성

라우트 `/watchlist`. 페이지 콘텐츠 영역(좌측 글로벌 내비게이션은 `AppShell` 소관, 본 페이지 범위 밖).

1. **페이지 헤더** — 제목 "관심 종목". (상단 동기화 시각·알림·프로필은 AppShell 크롬, 범위 밖.)
2. **툴바** — 검색(종목명/티커), 정렬 드롭다운, 시장 드롭다운, 위험 필터 드롭다운, **필터 초기화**,
   우측 **[+ 종목 추가]**(주요 버튼).
3. **요약 카드 4종** — 각 카드: 라벨+아이콘 / 큰 값 / 전일 대비 델타(±) / 미니 시각화 자리.
   - 전체 관심 종목 (예: 28개, +2)
   - 위험 증가 종목 (예: 3개, +1)
   - 추가 리서치 필요 (예: 5개, +1)
   - 평균 현금 연관도 (예: 58%, +4%p)
4. **2단 레이아웃**:
   - **좌(메인)**: 관심 종목 목록 테이블 카드.
   - **우(레일)**: AI 관찰 패널.

### 테이블 컬럼

`★ 즐겨찾기` · `종목`(로고+티커+이름) · `상태`(Badge) · `변화율(1D)`(±% + 스파크라인 자리[#19]) ·
`뉴스 위험도`(Badge) · `밸류에이션`(Badge) · `테마 과열`(Badge) · `AI 판단`(Badge) ·
`마지막 갱신`(타임스탬프) · `⋮`(행 메뉴).

- 변화율은 부호별 색상. 스파크라인은 이번 라운드 자리표시(텍스트/빈 영역), 실제 차트는 #19.
- 행/심볼 클릭 → `/research/:symbol`. 행 메뉴: 리서치 보기·결정 기록·알림 설정·관심 해제 등(인앱).
- 테이블 카드 헤더 도구: **열 설정**(컬럼 토글), **내보내기**(자리/후속), **전체화면**(자리/후속).
- 페이지네이션은 `Table`의 `pagination` 재사용.

### AI 관찰 레일

- **관찰 메모** — AI 관찰 코멘트 목록(편집 아이콘은 자리, 실제 편집은 후속).
- **추가된 관심 종목** — 최근 추가 종목 리스트(티커·이름·상태 Badge·추가 시각, 더 보기).
- **알림 설정** — 뉴스 위험도·AI 판단 변경·테마 과열 임계값 미리보기(자리, 실제 설정은 알림 이슈).

## 도메인·Mock 확장 (선행 또는 본 task 포함)

새 필드·모델이 필요하다(`shared/model`·`shared/mock`). 차트 데이터는 단순 배열/수치로만 추가.

- `Stock` 확장: `themeHeat: RiskLevel`, `lastUpdatedAt: string`, `isFavorite: boolean`.
  (로고는 별도 필드 없이 **심볼 이니셜로 대체 렌더**. 변화율 스파크라인용 `changeSeries?: number[]`는
  선택 — 표시는 #19에서.)
- 신규 모델:
  - `WatchlistSummaryCard`(또는 `WatchlistSummary`) — 카드별 `label`·`value`·`deltaLabel`·`trend` 키.
  - `WatchlistObservation` — 관찰 메모 항목(`text` 또는 `title`/`body`). 기존 `AiBriefing` 재사용 검토.
  - `RecentWatchlistItem` — `symbol`·`name`·`status`·`addedAt`.
  - `WatchlistAlertSetting` — `label`·`value`(임계값 미리보기). 기존 `AlertRule`와 관계 정리.
- Mock: `mockStocks`에 신규 필드 채움 + `mockWatchlistSummary`·`mockWatchlistObservations`·
  `mockRecentWatchlist`·`mockWatchlistAlertSettings` 추가. 모두 `satisfies`.

## 상태·파생 로직

- `useState`: 검색어, 시장/위험 필터, 정렬 키·방향, (즐겨찾기 토글은 로컬 상태 또는 mock 기준 표시).
- `useMemo`: 원본 → 필터 → 정렬 → 표시 행. 요약 카드 수치는 mock 또는 파생.
- 필터 초기화: 모든 필터/검색을 기본값으로 되돌림.

## 재사용·신규 컴포넌트 판단

- 기존 `Table`/`Badge`/`Button`/`Input`/`Card` 최대 재사용.
- **신규 공통 후보**: 드롭다운 Select(툴바·다른 페이지 재사용 신호), 행 케밥 메뉴/드롭다운 메뉴.
  2곳 이상 재사용 신호면 `shared/ui`로 분리(과도한 추상화 금지). Codex는 신규 공통 컴포넌트 추가가
  필요하면 보고 후 진행한다.

## Out of Scope

- **본격 분석 차트(캔들·거래량·비교) = 이슈 19**. (미니 시각요소는 본 라운드에 `recharts`로 포함 —
  시안 충실화 재결정 참조.)
- 실제 API·서버 상태(이슈 17), Loading/Empty/Error 공통 상태 컴포넌트 신설(이슈 18).
- **종목 추가**·**내보내기**·**전체화면**·**열 설정**·관찰 메모 **편집**·**알림 설정** 실제 동작 — 본 라운드는
  UI 자리/네비게이션까지. 페이지네이션·"전체 N개" 카운트도 정적 자리표시. 실제 플로우는 각 후속 이슈.
- 색상/토큰 일관화: 등락 emerald/rose·브랜드 마크 hex·blue/cyan/red 강조색은 원시 Tailwind/리터럴 사용 →
  의미 토큰화 후속.
- **공통 `Table` 재사용 재검토**: 행 인터랙션 요구로 본 라운드는 직접 `<table>` 채택. 재사용 신호 시 공통화.
- 다른 페이지(Signals/Research/Decision Log/Dashboard).

## 결정 (2026-06-22 확정)

- **로고**: 정적 자산을 두지 않고 **심볼 이니셜/브랜드 마크 대체**(단색 배경 + 첫 글자/기호). 자산 의존 회피.
- **즐겨찾기(★)**: mock `isFavorite` 기준 표시 + 토글은 로컬 상태로 즉시 반영(영속화는 후속).
- **정렬**: 단일 키 + 방향 + **"사용자 설정"(mock 원순서) 기본**. 다중 키·프리셋은 후속.
- **미니 시각요소**: 기존 의존성인 **`recharts`**로 구현(LineChart 스파크라인, BarChart 막대,
  PieChart 도넛). 대시보드와 차트 라이브러리 사용 방식을 맞춘다.
- **테이블**: 공통 `Table` 대신 **페이지 로컬 `<table>`**(행 인터랙션 충실화). 공통화는 후속 재검토.
