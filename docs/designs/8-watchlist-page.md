# Design — Issue 8: Watchlist 관심 종목 페이지

## 목적

관심 종목의 상태·변화율·뉴스 위험도·밸류에이션·AI 판단을 테이블로 확인하고,
검색·필터·정렬로 좁혀 보며, 행에서 리서치 상세(`/research/:symbol`)로 이동한다.

## 범위

- `WatchlistPage`를 플레이스홀더에서 실제 화면으로 교체.
- 데이터는 `shared/mock`의 `mockStocks`(NVDA/AAPL/TSLA/MSFT)를 사용. API 연동·서버 상태 없음.
- 공통 컴포넌트 우선: 기존 `Table`/`Badge`/`Button`/`Input`/`Card`를 재사용한다.

## 화면 구성

라우트 `/watchlist`. 위에서 아래로:

1. **헤더** — 제목·설명(기존 페이지 헤더 패턴 재사용).
2. **요약 카드 영역** — 관심 종목 수, 위험(뉴스 위험도 '높음') 종목 수, 상승/하락 종목 수 등
   집계 카드 몇 개. `Card` 재사용, 그리드 배치.
3. **검색·필터 바** — 심볼/이름 검색 입력(`Input`), 시장 필터, 뉴스 위험도 필터, 정렬 기준 선택.
   필터·정렬·검색은 클라이언트 측 `useMemo` 파생으로 처리(상태는 `useState`).
4. **관심 종목 테이블** — `Table<Stock>`. 컬럼·정렬·행 액션·행 클릭 이동.

## 컴포넌트 책임

| 요소 | 위치 | 책임 |
| --- | --- | --- |
| `WatchlistPage` | `pages/ui` | 데이터 로드(mock)·필터/정렬 상태 보유·하위 조합. 도메인 로직 최소화. |
| 요약 카드 | 페이지 내부 또는 `widgets` | 종목 배열에서 집계 수치 계산·표시. 재사용 신호 적으면 페이지 내부 조립. |
| 필터 바 | 페이지 내부 또는 `features` | 검색어·시장·위험도·정렬 입력 제어. 제어 컴포넌트로 상위 상태에 위임. |
| 테이블 | `Table` 재사용 | 컬럼 정의로 종목 행 렌더. 상태·위험도는 `Badge`로 표시. |

- 컬럼: 심볼/이름, 시장, 현재가, 변화율, 상태(`Badge status`), 뉴스 위험도(`Badge riskLevel`),
  밸류에이션, AI 판단. 변화율은 부호별 색상 처리.
- 행 액션: 행별 액션 메뉴(예: 리서치 보기 / 결정 기록). 네이티브 다이얼로그 금지 — 인앱 UI/네비게이션.
- 행 또는 심볼 클릭 → `navigate('/research/' + symbol)`.

## 상태·파생 로직

- `useState`: 검색어, 시장 필터, 위험도 필터, 정렬 키/방향.
- `useMemo`: 원본 `mockStocks` → 필터 적용 → 정렬 → 표시 행. 정렬은 변화율·현재가 등 수치 기준.
- 필터 옵션(시장·위험도)은 mock에서 파생하거나 도메인 enum(`riskLevels`)에서 가져온다.

## 재사용·신규 컴포넌트 판단

- 신규 공통 프리미티브는 만들지 않는 것을 기본으로 한다(기존 `shared/ui`로 충족).
- 만약 Select/드롭다운이 필요하고 기존에 없으면: 우선 네이티브 `<select>`를 `Input` 스타일에 맞춰
  쓰거나, 2곳 이상 재사용 신호가 있을 때만 `shared/ui`에 공통화(과도한 추상화 금지).
  Codex는 새 공통 컴포넌트 추가가 필요하다고 판단되면 보고 후 진행한다.

## 테스트

- `WatchlistPage` 렌더 테스트(Testing Library):
  - NVDA/AAPL/TSLA 등 mock 종목이 표시된다.
  - 상태·변화율·뉴스 위험도·밸류에이션·AI 판단 셀이 렌더된다.
  - 필터/검색 입력이 행 집합을 좁힌다.
  - 행(또는 심볼) 클릭 시 `/research/:symbol`로 이동(라우터 mock으로 검증).

## Out of Scope

- 실제 API·서버 상태(이슈 17), 차트(이슈 19), Loading/Empty/Error 공통 상태 컴포넌트(이슈 18, 본 페이지는
  `Table`의 기본 empty/loading만 사용).
- 알림 토스트 인프라 신설(필요 시 기존/후속 이슈). 본 페이지는 네비게이션 위주.
