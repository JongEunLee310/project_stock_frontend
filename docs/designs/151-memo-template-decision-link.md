# Design — Issue 151: 내 메모 템플릿·Decision Log 연결

리서치 상세의 "내 메모"를 자유 입력에서 구조화 기록으로 발전시키고,
판단 기록(Decision Log) 작성 흐름과 연결한다. 리서치 재설계 3차의
마지막 항목이다.

## Scope Decision

- **BE 변경 없음.** 메모 계약(`buy-checklist`의 `memo: string`)은
  유지하고, 템플릿은 텍스트 스캐폴드 삽입으로 구현한다. 구조화 필드
  분리(BE 계약 변경)는 사용 패턴이 확인된 뒤 후속으로 검토한다.
- Decision Log 연결은 **symbol 프리필 딥링크**로 한정한다. 메모 내용을
  판단 기록 reason으로 복사하는 자동화는 이번 범위가 아니다 (판단
  기록은 판단 시점의 요약이지 메모 전문이 아님).

## 1. 메모 템플릿 — `src/pages/ui/ResearchPage.tsx` (내 메모 카드)

- 템플릿 상수 (모듈 상수, 6개 섹션 — 이슈 명세 그대로):

  ```
  [투자 가설]

  [긍정 근거]

  [반대 근거]

  [매수 조건]

  [철회 조건]

  [다음 확인 날짜]
  YYYY-MM-DD
  ```

  재검토 조건 기록은 철회 조건·다음 확인 날짜 섹션이 담당한다.

- 카드 헤더(제목 옆)에 "템플릿 적용" 버튼:
  - 메모가 비어 있을 때(공백만 포함)만 활성. 내용이 있으면 disabled
    (`aria-disabled` 아님 — 실제 disabled + title 안내 "메모를 비우면
    템플릿을 적용할 수 있습니다").
  - 클릭 시 템플릿 문자열을 draft로 설정하고 기존 자동 저장 흐름
    (debounce·저장 상태 표시)을 그대로 태운다 — 저장 경로 신설 없음.
- textarea placeholder를 템플릿 존재를 알리는 문구로 갱신 (예: "판단
  근거를 남기거나, 템플릿 적용으로 구조화해 보세요.").

## 2. Decision Log 연결

- **리서치 → 판단 기록**: HeaderCard의 "판단 기록" 버튼이
  `/decision-log?symbol={research.symbol}`로 이동 (기존 단순 이동
  대체).
- **`src/pages/ui/DecisionLogPage.tsx`**: `useSearchParams`로 `symbol`
  쿼리를 읽어 작성 폼의 종목 필드 초기값으로 프리필한다.
  - 프리필은 마운트 시 1회 (이후 사용자 수정 자유). 폼에 이미 입력된
    상태를 덮어쓰지 않는다 — 초기 state 시드로만 사용.
  - 유효성은 기존 폼 규칙 그대로 (trim·대문자 정규화 기존 로직 재사용).
- **판단 기록 → 리서치**: 기존 테이블의 심볼 링크가 이미 리서치 상세로
  연결되어 있으므로 변경 없음.

## Test

- ResearchPage: 메모 빈 상태에서 "템플릿 적용" 클릭 시 textarea에 6개
  섹션 삽입·자동 저장 트리거(debounce 후 PUT 호출 단언), 메모에 내용이
  있으면 버튼 disabled, "판단 기록" 버튼이 symbol 쿼리를 포함한 경로로
  이동.
- DecisionLogPage: `?symbol=NVDA` 진입 시 종목 필드 프리필, 쿼리 없을
  때 기존 동작 회귀 없음, 프리필 후 사용자 수정 가능.
- 기존 메모 자동 저장·체크리스트 테스트 회귀 없음.

## Out of Scope

- BE 계약 변경 (메모 구조화 필드·재검토 알림).
- 메모 → 판단 기록 reason 자동 복사.
- 다음 확인 날짜 기반 리마인더 (알림 파이프라인 후속).
