# Design — Issue 142: 리서치 상세 레이아웃 정밀 정렬 (research.png 2단 구성)

PR #140으로 데이터·기능은 연결됐다. 이 단계는 화면 배치와 카드 세부 구성을
research.png 시안에 맞춘다. 데이터 소스·훅은 바꾸지 않는다 (신규 API 없음).
우선순위 근거: PR #153 Q2 답변 — 목록 고도화보다 상세 콘텐츠 구체화 우선.

## 시안 구조 (research.png)

```text
[헤더 밴드 — 전폭 Card]
로고칸·심볼·회사명·시장·섹터 | 현재가·등락 | AI 투자 스탠스 박스 | 메트릭 그리드

[본문 상단 2단]
좌(약 2/3): 차트 카드 — 탭(가격·밸류에이션·실적) + 기간칩 + 차트 + 데이터 캡션
우(약 1/3): AI 브리핑 카드, 핵심 리스크 카드

[본문 하단 열]
뉴스 및 공시 요약 | 촉매 타임라인(자리) | 의사결정 체크리스트 | 내 메모
```

## Page 변경 — `src/pages/ui/ResearchPage.tsx` (레이아웃 재배치)

- **헤더 밴드** — 기존 HeaderCard를 시안 구성으로 재배치한다.
  - 좌측: 심볼 이니셜 칸 · 심볼 · 회사명 · `{market} · {sector}`.
  - 중앙: 현재가(`price`+`currency`)와 등락(`change`, `changePercent`),
    상승 emerald·하락 red (기존 포맷터 재사용).
  - AI 투자 스탠스 박스: 라벨(`stance`) + `신뢰도 {n}%` 배지. 기존
    워치리스트/판단 기록 버튼은 박스 밖 우측 상단 액션 영역으로 이동하고
    관심종목 버튼과 나란히 둔다.
  - 메트릭 그리드(2열)에 시가총액 · 섹터 · 52주 범위 · 다음 실적 발표 ·
    평균 목표주가(+upside) 표시 (기존 타일 데이터 유지, 배치만 변경).
- **차트 카드 (좌측 상단)** —
  - 상단 탭: `가격`(활성) · `밸류에이션` · `실적`. 뒤 둘은 disabled
    (`aria-disabled`, "준비 중" 안내) — #149에서 활성화.
  - 기간칩(1D/1M/3M/6M/1Y)·차트·`차트 데이터: {source} · {lastUpdatedAt}`
    캡션은 기존 구현 유지. 카드 우측의 "평균 목표주가" 보조 블록은
    헤더 밴드로 흡수됐으므로 제거한다.
- **AI 브리핑 카드 (우측 상단)** — 기존 briefing 카드를 우측 컬럼으로
  이동. headline·body·갱신 시각 구성 유지. 구조화 불릿은 #145 범위.
- **핵심 리스크 카드 (우측, 브리핑 아래)** — 기존 RiskPanel 이동.
  "리스크 수준: {종합}" 헤더 표기 유지.
- **하단 열 (xl 기준 4칸, 축소 시 wrap)** —
  - 뉴스 및 공시 요약: 기존 ReportsPanel. 제목은 "뉴스 및 공시 요약" 유지.
  - 촉매 타임라인: 자리 카드 신설 — EmptyState("예정 이벤트 데이터가
    아직 수집되지 않았습니다."). 데이터 연결은 #147(BE #269 후).
  - 의사결정 체크리스트: 기존 ChecklistPanel.
  - 내 메모: 기존 메모 카드 (자동 저장 표시 유지).

레이아웃 이동 시 컴포넌트 내부 로직(저장·debounce·관심종목 토글)은 변경
하지 않는다. 그리드 클래스와 카드 배치·헤더 구성만 바꾼다.
