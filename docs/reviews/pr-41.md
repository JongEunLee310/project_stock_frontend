# PR #41 Local Review — 공통 차트 컴포넌트 1차 구현 (이슈 19)

## Review Summary

이슈 19. 다크 테마 공통 차트 컴포넌트(`Sparkline`/`LineChart`/`DonutChart`/`BarChart`)를
`src/shared/ui/charts`에 추출하고, Dashboard/Watchlist/Signals에 인라인으로 산재하던 `recharts`
호출을 공통 컴포넌트로 교체했다. Research 가격 차트 자리표시를 공통 `LineChart`로 연결했다.
신규 차트 라이브러리 추가 없이(recharts 유지) **표현 레이어 공통화 + M2 이월 부채(폭 처리 불일치)
해소**가 핵심이다. 설계 `docs/designs/19-chart-components.md`와 일치. 마일스톤 3 첫 라운드.

검토 항목:

- **공통 컴포넌트 API 일관성**: 4종 모두 `data`/`height`/`width?`/`responsive?`/`color?`/
  `ariaLabel?`/`className?` 동일 시그니처. barrel(`shared/ui/charts/index.ts` →
  `shared/ui/index.ts`)로 export. 공통 컴포넌트 우선 원칙 부합.
- **폭 처리 수렴(M2 이월 해소)**: `useMeasuredChartWidth` 단일 훅으로 고정 `width`(jsdom 결정성)와
  반응형 `ResizeObserver` 측정(미지원/SSR 폴백 `fallbackWidth`)을 한 컴포넌트가 모두 지원.
  Dashboard/Watchlist 고정 vs Signals 측정으로 갈리던 방식이 하나로 합쳐졌다.
- **결정성 유지**: 모든 차트 `isAnimationActive={false}`, `ResponsiveContainer` 미사용(명시
  width/height 또는 자체 측정만). `TZ=UTC pnpm test` 66/66 통과로 jsdom 결정성 확인.
- **접근성 중앙화**: `getChartAccessibility`로 장식 차트 `aria-hidden`, 의미 차트 `role="img"`+
  `aria-label`. Signals 신뢰도 원형 링(`ConfidenceRing`, 자체 SVG `role="meter"`)은 차트 컴포넌트
  대상이 아니라 그대로 유지 — 접근명 보존.
- **소비처 교체 완전성**: 4개 페이지(Dashboard/Watchlist/Signals/Research) 인라인 `from 'recharts'`
  import 전면 제거(grep 0건). Research 가격 탭 자리표시 → 공통 `LineChart`(`aria-label` 부여).
- **색 단일 출처화**: `chartTheme`가 기존에 페이지마다 흩어졌던 원시 색을 한 상수로 모음(라인/막대/
  도넛 팔레트·축·그리드). 단일 출처가 생겨 후속 @theme 토큰화가 쉬워짐.
- **도메인/Mock 무변경**: 차트는 기존 mock 파생만 사용. 회귀면은 페이지 교체에 한정 — 66/66 유지.

## Blocking

## Suggestions

- **`chartTheme` 원시 hex → @theme 토큰화(이월)**: 라인/막대/도넛/등락 색이 원시 hex(`#5fa8ff`,
  `#34d399`/`#fb7185` 등)다. 한 상수로 모은 것은 개선이나 의미 토큰화(@theme `app-*`/`cockpit-*`)는
  여전히 이월. 단일 출처가 생겼으므로 후속 토큰화 비용은 낮아졌다(비차단).
- **`LineChartPoint`/`BarChartPoint` 인덱스 시그니처 타입**: `{ [key: string]: number | string }`로
  느슨해 호출부 키 오타 방어가 약하다. 향후 제네릭 `<T>`로 좁히면 `xDataKey`/`yDataKey` 안전성↑(비차단).
- **번들 크기**: 빌드 청크 경고(>500kB)는 recharts 기존 사용에서 비롯된 것으로 회귀 아님. 공통화로
  import 표면이 정리됐으니 추후 code-split/manualChunks 검토 여지(이월).
