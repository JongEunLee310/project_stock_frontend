# PR #36 Local Review — Dashboard(AI 투자 관제실) 페이지 (task-014 / 이슈 7)

## Review Summary

`/`(index) 플레이스홀더 `DashboardPage`를 시안 기반 실제 집계 허브로 교체. 헤더 "AI 투자 관제실" + AI Today
Brief 카드 4 + 관심 종목 상태 `Table<Stock>` + AI 브리핑 + 우선 확인 큐 + 시그널 상위 3 + 최근 판단 기록
`Table<DecisionLog>`를 구성했다. 시안 충실을 위해 도메인을 소폭 확장(Part A)하고 그 위에 페이지를 구현
(Part B)했다. 설계 `docs/designs/7-dashboard-page.md`, 핸드오프 `.codex/tasks/task-014-dashboard-page.md`와
구조가 일치한다.

검토 항목:

- **확정 결정 준수(2건)**: ① 핵심 지표 = PER/PEG 숫자 — `Stock`에 `per`/`peg` 추가, `mockStocks` 4종을 시안
  값(NVDA 60.3/1.32·AAPL 28.7/2.36·TSLA 88.1/3.04·MSFT 31.6/2.36)으로 전수 채움. ② Today Brief 델타 표시 —
  `DashboardSummary`에 델타 4필드 추가, 카드에 "전일 대비 +N" 노출. 둘 다 설계 표와 일치.
- **파괴적 변경 회피**: 필수 필드 추가(`Stock.per/peg`, `PriorityQueueItem.title`)에도 `satisfies` 유지 +
  mock 전수 채움 → `typecheck` 통과. `AiBriefing`의 신규 필드(`riskHeadline?`/`riskChecks?`)는 **선택**으로
  두어 `mockStockResearch`의 인라인 briefing 4종을 건드리지 않았다(블라스트 반경 최소).
- **집계 허브 = 기존 mock 재사용**: 관심 종목(`mockStocks` 상위 4)·시그널(`mockSignals` priority 오름차순
  상위 3)·최근 판단 기록(`mockDecisionLogs` createdAt 내림차순 상위 4)을 재사용. 대시보드 전용 mock 3종
  (`mockDashboardSummary`/`mockAiBriefing`/`mockPriorityQueue`)은 기존 어느 곳에서도 미사용이라 한국어
  재작성이 안전.
- **공통 컴포넌트 재사용**: 두 표 모두 공통 `Table<T>`(task-006), 상태/위험도/판단유형은 `Badge`
  (status/riskLevel/decisionType 오버로드), 카드 `Card`, "자세히 보기" `Button`. 종목은 `/research/:symbol`
  `Link`. 인라인 색상·뱃지 스타일 복제 없음.
- **차트 라이브러리 미도입(이슈 19 경계 준수)**: Today Brief 미니 시각요소(스파크라인/막대/도넛)와 관심
  종목 스파크라인은 인라인 SVG·CSS로만 구현. 데코용은 `aria-hidden`, 종목 스파크라인은 `role="img"` +
  `aria-label`로 접근성 처리.
- **타임존 안전**: 시간 포매터 `timeZone: 'Asia/Seoul'` 고정. 시그널/판단 기록 정렬은 `priority`·고정 mock
  `createdAt` 기준이라 현재 시각·타임존에 독립. 테스트는 종목/판단유형/수치/링크 목적지로 단언(시간 문자열
  단언 회피).
- **셸 범위 준수**: 시안 사이드바의 시장 요약은 전역 `MarketSummary` 위젯으로 이미 존재 → 대시보드 페이지는
  재구현하지 않음(공유 셸 무변경). `App.test`의 대시보드 heading 단언만 `Market Command Center` →
  `AI 투자 관제실`로 갱신(라우팅 교체 선례 허용).
- **보호 파일 무변경**: `src/index.css` `@theme` 변경 없음 — 기존 app-*/status-* 토큰으로 구현.

로컬 검증: `format:check`·`lint`·`typecheck`·`TZ=UTC pnpm test`(58/58, DashboardPage 6건 신규)·`build` 모두
통과.
