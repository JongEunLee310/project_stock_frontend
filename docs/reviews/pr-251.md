# PR #251 로컬 리뷰 — 새 판단 작성 AI 보조 UI (#250)

## Review Summary

판단 기록 재설계 FE 1차(#249, 머지됨)의 작성 폼에 AI agent 보조를 추가합니다. BE `POST /api/v1/decision-logs/assist`(`project_stock` #356)를 소비해 4종 제안을 받고, 사용자가 확인한 뒤에만 정식 폼 필드에 반영합니다.

`features/decision-log`의 `dto.ts`·`adapters.ts`·`queries.ts`에 assist 요청/응답 타입과 `useDecisionAssist` 뮤테이션 훅을 더했습니다. 작성 패널(`widgets/decision-form-panel/DecisionFormPanel.tsx`)에 "AI 보조" 액션을 두고, 제안 표시는 별도 위젯 `DecisionAssistPanel.tsx`로 분리했습니다. 제안은 `assistResult` 상태로 폼 상태와 분리해 보관하며, 각 항목의 [적용]을 눌러야 `onApplyRationale`·`onApplyCounterArgument`·`onApplyRisk` 콜백으로 해당 폼 필드에 반영됩니다. [수정]은 제안을 편집 후 적용, [무시]는 해당 제안을 소거합니다. 행동 편향 라벨은 `shared/model/behavioralBias.ts`로 추가했고, 미지 태그는 기존 관례대로 원문 폴백합니다.

이번 리뷰는 "확인 후 저장" 원칙(적용 전 정식 필드 불변), AI 자동 확정 금지, 상태 분리, BE 계약 소비를 축으로 봤습니다.
