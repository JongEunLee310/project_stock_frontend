## Suggestions

`formatLocalDateTime`은 입력이 날짜만 있는 문자열(`'YYYY-MM-DD'`)일 경우 `new Date()`가 이를
UTC 자정으로 해석한 뒤 로컬 getter로 변환하므로, UTC보다 느린 타임존(예: 미주권)에서는
날짜가 하루 앞당겨질 수 있습니다. 현재 실제 호출부(`priceSeries.lastUpdatedAt`)는 항상 `Z`가
붙은 전체 ISO 문자열이라 실질적인 위험은 낮지만, 이 함수가 다른 곳에서도 재사용될 가능성을
고려하면 날짜 전용 입력에 대한 테스트 케이스를 하나 추가해 두는 편이 이후 재사용 시
안전할 것 같습니다.
