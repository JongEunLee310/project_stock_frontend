# PR #93 — 시장 요약 카드 와이어링 (feat/market-indices-wiring)

리뷰어: Claude Code (Opus, 오케스트레이터). 구현: Codex. 브랜치: feat/market-indices-wiring → main. 관련: FE #87, 설계 76, Pair BE 061(PR #157).

## Review Summary

설계 76대로 `src/widgets/MarketSummary.tsx`의 하드코딩 `marketSummaries` 배열과 고정 푸터를 BE 시장 지수 API(`GET /market/indices`)로 전환했습니다. briefing·watchlist-observations 슬라이스 패턴을 그대로 따라 신규 슬라이스 `src/features/market-indices/`(dto·adapter·query)를 추가하고, 위젯을 로딩·에러·빈 목록·정상 렌더 분기 구조로 바꿨습니다.

`useMarketIndices()`는 `GET /market/indices`를 단일 호출하고(watchlist-observations와 달리 first-entity 해소가 없어 구조가 단순), envelope `data` 리스트를 `adaptMarketIndexBoard`로 composite 도메인 `MarketIndexBoard { indices, referenceAt }`에 매핑합니다. `value`·`change_percent`는 BE Decimal이 문자열로 직렬화된 값이라 `parseDecimal`로 number 변환하고 `null`이면 `0`으로 방어하며, `referenceAt`은 첫 항목의 `reference_at`(빈 배열이면 `null`)을 씁니다.

설계의 결정이 모두 반영됐습니다: (1) 독립 슬라이스 배치, (2) dto snake_case·문자열 보존, (3) composite 도메인·`reference_at` board 승격, (4) `parseDecimal` 방어 adapter, (5) 단일 호출 query, (6) 부호 기반 tone(VIX quirk 미승계), (7) `change_percent` 퍼센트 단위 함정 처리(`formatPercent(changePercent / 100, 2)` + 양수 `'+'` 접두).

## Blocking

None.

## Suggestions

**S1 · 부호 접두 경계(`> 0`) vs tone 경계(`>= 0`) (비차단)**

변동률 부호 접두는 `changePercent > 0`일 때만 `'+'`를 붙이고, tone은 `changePercent >= 0`을 상승(emerald)으로 봅니다. 값이 정확히 `0`이면 `'+'` 없이 `0.00%`를 emerald로 표시합니다. `0%`에 `'+'`를 붙이지 않는 편이 자연스러워 의도된 절충이며, 실데이터에서 변동률이 정확히 0일 확률도 낮습니다. 현 단계 비차단입니다.
