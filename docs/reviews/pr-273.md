# PR #273 로컬 리뷰 — 뉴스·공시 토픽 맵 Cytoscape 시각화 (#202)

## Review Summary

뉴스·공시 인텔리전스(에픽 #198) FE 1차의 토픽 맵 시각화로, 개요 페이지의 토픽 맵 자리를 `GET /topics/map` 실연동 + Cytoscape.js 렌더로 교체합니다. 브랜치는 #200(#272)·#199(#271) 위에 스택돼 있으나 PR base는 main이며 커밋은 2건(Cytoscape 의존성 추가, 구현)입니다.

`src/features/news-insights/`에 토픽 맵 dto·adapter·`useNewsTopicMapQuery`를 추가하고, `src/widgets/TopicMap/`에 Cytoscape 렌더 위젯을 신설했습니다. 위젯은 `lazy(() => import('react-cytoscapejs'))` + `Suspense`로 Cytoscape를 지연 로딩해 별도 청크(gzip 144kB)로 분리하고, 언마운트 시 `cy.destroy()`로 인스턴스를 정리합니다. 노드 크기는 언급량·모멘텀, 색은 감성(score 버킷), edge 굵기는 `mapData(strength, …)`로 매핑해 연관 강도와 감성을 별도 시각 채널로 둡니다. 클릭 핸들러는 `type !== 'TOPIC'`이면 무시하고 TOPIC 노드만 `/news/topics/:topicId`로 이동합니다. 카테고리·감성·강도 3종 범례를 텍스트로 병기합니다.

이번 리뷰는 강도/감성의 시각 분리, Cytoscape 생명주기·번들 영향, 클릭 네비게이션의 노드 타입 필터를 축으로 봤습니다.

## Blocking

None.

## Suggestions

**S1. Cytoscape 지연 로딩·번들 분리 — 메인 번들 영향 없음.** `lazy`+`Suspense`로 Cytoscape가 별도 청크(`react-cytoscape.modern-*.js`, 448kB/gzip 144kB)로 분리돼, 기존 chunk 경고가 있는 메인 번들을 키우지 않습니다. 토픽 맵 진입 시에만 로드됩니다. 후속 조치는 불필요합니다.

**S2. `@types/cytoscape` deprecated 경고 — 무해.** cytoscape 3.x가 자체 타입을 제공해 `@types/cytoscape`가 deprecated로 표시되나, `@types/react-cytoscapejs`가 이를 참조하고 typecheck가 통과하므로 기능·타입에 문제가 없습니다. 후속 정리 시 제거를 검토할 수 있습니다.

## Questions

**Q1. TOPIC 노드만 네비게이션 — 확인 완료.** 클릭 핸들러가 `event.target.data('type') !== 'TOPIC'`이면 반환해, KEYWORD 노드 클릭 시 잘못된 topicId로 이동하지 않습니다. 리뷰 중 확인해 해소했습니다.

**Q2. Stacked 브랜치 머지 순서.** 브랜치가 #272·#271 위에 있어 이 PR diff는 하위 머지 전까지 그 변경을 포함합니다. PR base는 main이므로 #271 → #272 → #273 순서로 머지하면 diff가 각 단위로 자동 정리됩니다. 코드 판단이 아니라 머지 순서 확인 사항입니다.

## Final Recommendation

머지 가능합니다(Q2의 머지 순서 조건). `GET /topics/map` 연동, 연관 강도(edge 굵기)와 감성(node 색)의 시각 분리, TOPIC 노드 클릭 네비게이션, Cytoscape 지연 로딩·언마운트 정리가 구현과 일치함을 확인했습니다. 범위는 토픽 맵으로 지켜졌고 토픽 상세(#203)는 네비게이션만 배선했습니다. Protected Files 변경은 없으며 의존성 추가는 승인된 Cytoscape뿐입니다. 추가된 테스트는 query·adapter와 위젯 렌더·클릭 네비게이션을 덮습니다. Blocking은 없고, Suggestions(S1·S2)는 번들 분리 확인과 무해한 deprecated 경고이며, Questions(Q1은 노드 타입 필터 확인, Q2는 머지 순서)는 정리됐습니다.
