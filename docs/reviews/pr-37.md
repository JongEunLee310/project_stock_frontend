## Suggestions

- **`@theme` 토큰 값 수정(add-only 관례 벗어남)**: `src/index.css`의 기존 app-* 색 8종과 `--spacing-page`를
  **값 변경**했다. 평소 `@theme`는 추가만 허용하는 보호 성격으로 다뤄왔다. 이번엔 시안 톤 통일을 위한 의도적
  전역 테마 조정으로 판단되나, 전역 색 변경은 모든 페이지에 영향을 주므로 다른 페이지 회귀(대비/가독성)를
  한 번 훑어보길 권장(본 PR 차단 아님). 향후 토큰 값 변경은 ADR 또는 명시 합의로 남기는 편이 안전.
- **신규 의존성 2종(`recharts`+`react-is`)**: 번들 사이즈 증가 요인. 미니 데코 시각요소만 쓰는 현 단계에선
  과한 의존일 수 있으나, 이슈 19 본격 차트에서 재사용 전제라면 선투자로 합리적. tree-shaking 확인 권장.
- **셸 정적 자리표시값**: Topbar "동기화 14:32"·alerts 뱃지 "6"·MarketSummary "데이터 기준 14:31 KST"는
  하드코딩 표시값이다. 실제 데이터 연동은 후속.
- **색상 토큰화(이월·여전히 유효)**: 등락 emerald/rose·카테고리 톤은 여전히 원시 Tailwind 색. `@theme`
  app-* 토큰(상승/하락) 통일 후속.
