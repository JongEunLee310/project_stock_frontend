# PR #29 Local Review — 공통 Table 컴포넌트 (task-006 / 이슈 12)

## Review Summary

task-006 핸드오프 구현 리뷰. `shared/ui`에 제네릭 `Table<T>`를 추가했다. 컬럼 정의(`TableColumn<T>`) 기반 렌더, Empty/Loading 상태, 클라이언트 페이지네이션(제어/비제어), 행별 액션 슬롯(`rowAction`)을 지원한다. 시맨틱 테이블 마크업과 헤더 `scope="col"`로 접근성을 확보했고, 스타일은 기존 `shared/ui` 디자인 토큰(`app-*`, `rounded-card`, `Button` variant)을 그대로 따른다. 핸드오프 Goal·Implementation Scope·Test Requirements를 충족하며 Out of Scope(페이지 통합·실데이터·서버 사이드 정렬/필터·가상 스크롤) 침범 없음.

검토 항목:

- 제네릭 `Table<T>` — 행 타입에 제네릭, 컬럼 설정으로 셀 렌더링. 불필요한 추상화 없이 현재 요구 범위(정렬 옵션은 플래그/`sr-only` 표시만, 실제 정렬 로직은 미구현)로 한정 — 스코프 준수.
- 페이지네이션이 제어(`pagination.page` 지정)·비제어(`defaultPage` + 내부 state) 모두 동작. `clampPage`로 경계 보호, 컬럼/액션 수 기반 `colSpan` 처리로 Empty/Loading row가 표 폭에 맞음.
- 접근성: `table/thead/tbody/th/td` 시맨틱, 헤더 `scope="col"`, `aria-label` 주입 가능. 테스트가 `getByRole('table'|'columnheader')`로 확인.
- 기본 메시지(로딩/Empty) 한국어 합리적 기본값 + 주입 가능. props 기본값 합리적.
- `src/shared/ui/index.ts` 배럴에 `Table` + 타입(`TableColumn`/`TableColumnAlign`/`TablePagination`/`TableProps`) export. `src/shared/README.md`에 용도 한 줄 추가.

로컬 검증: `format:check`·`lint`·`typecheck`·`test`(21/21, Table 5건 포함)·`build` 전부 통과.

## Suggestions

- `sortable` 옵션이 현재 헤더에 `sr-only` "정렬 가능" 텍스트만 노출하고 실제 정렬 동작·시각 인디케이터가 없다. 핸드오프상 정렬 로직은 후속(페이지 task) 범위이므로 본 PR 차단 사유 아니나, 시각 표식 없는 `sortable`은 스크린리더 사용자에게만 "정렬 가능"이 들려 혼동 여지. 정렬 UI를 붙이는 후속 task에서 함께 마감 권장.
- 비제어 페이지네이션에서 `rows`가 외부에서 줄어 현재 페이지가 범위를 벗어나는 경우, 렌더 시 `clampPage`로 표시는 보정되지만 내부 `internalPage` state는 즉시 갱신되지 않는다(다음 이동 시 정상화). 현재 골격 범위에선 무해하나 실데이터 연동 페이지에서 점검 권장.
