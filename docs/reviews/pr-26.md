# PR #26 Local Review — 라우팅 구조 및 App Shell 레이아웃 (task-003 / 이슈 4·5)

## Review Summary

task-003 핸드오프 구현 리뷰. `react-router-dom`을 도입해 8개 주요 라우트와 NotFound를 레이아웃 라우트로 구성하고, 모든 페이지를 감싸는 App Shell(Sidebar/Topbar/MarketSummary/`<Outlet/>` 콘텐츠 슬롯)을 구현했다. 핸드오프 Goal·Implementation Scope·Test Requirements를 모두 충족하며, Out of Scope(페이지 실제 콘텐츠·디자인 토큰 정의·도메인 연동) 침범 없음. 보호 파일 변경 없음.

검토 항목:

- 라우트와 Sidebar 메뉴가 `shared/config/navigation.ts` 단일 소스에서 파생 — 핸드오프 "단일 소스 일관 파생" 요구 충족. `appRoutePaths`를 라우터(`router.tsx`)와 네비게이션(`navigationItems`)이 공유.
- 활성 메뉴는 `getActiveNavigationItem`이 `matchPrefix`(`/research`) 기반으로 중첩 경로(`/research/NVDA`)에서도 정확히 판정. `aria-current="page"`로 접근성 표시.
- App Shell이 레이아웃 라우트(`element: <AppShell/>` + children)로 전 라우트를 감싸고, NotFound(`path: '*'`)도 Shell 내부에 렌더 — 핸드오프 "모든 라우트를 감싸는 레이아웃 라우트" 요구 충족.
- 의존성은 `react-router-dom`만 추가(핸드오프 제약 준수). 그 외 추가 없음.
- 데스크톱 기준 `lg:grid-cols` 반응형, 토큰(`app-*`) 사용으로 task-002 토큰 재사용.
