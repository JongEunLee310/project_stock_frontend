# PR #278 로컬 리뷰 — 투자자 동향·투자자 반응 패널 (#264)

## Review Summary

개요 "투자자 동향"(§3.5)과 토픽 상세 "투자자 반응"(§5.7) placeholder 두 자리를 `/investor-flows` 실데이터로 교체한 PR입니다. 커밋은 구현 본체(`투자자 수급 패널 연동`)와 리뷰 수정(`fix: 투자자 수급 방향 막대 위치 클래스 수정`) 두 건입니다.

`src/features/news-insights/`에 investor-flows dto·adapter(`adaptNewsInvestorFlows`)·query(`useNewsInvestorFlowsQuery({ market, window, topicId? })`)를 추가하고 InvestorType·FlowDirection presentation 맵을 확장했습니다. 공용 위젯 `InvestorFlowPanel`을 신설해 개요(market="KR" 시장 전체)와 토픽 상세(market="KR" + topic_id)에서 `{ market, window, topicId?, title, context }` props로 재사용합니다. 개요는 피드/맵 행 아래에 배치하고 `plannedPanels`에서 investor-flow 항목을 제거했으며, 토픽 상세는 `investorReaction` placeholder를 대체했습니다.

위젯은 투자 주체별(외국인·기관·개인·ETF) 순매수/순매도를 방향 막대와 배지로 표시하고, 금액(`net_value`)은 Decimal 문자열이라 `parseDecimal`+`formatMoney`로만 표기해 float 산술을 하지 않습니다. 뉴스 내러티브 vs 수급 방향 정렬을 `narrative_alignment`로 판단해 일치("내러티브·수급 일치")·불일치("불일치 신호") 배지를 노출하고, `availability.available=false`면 빈 숫자를 만들지 않고 `fallback` 대체 지표를 안내합니다.

이번 리뷰는 계약 일치, Decimal 문자열 정밀도, 색+배지 병기와 불일치 신호, availability 처리, 공용 위젯 재사용에 따른 두 페이지 회귀를 축으로 봤습니다.

## Blocking

None.

## Suggestions

**S1. 방향 막대 위치 클래스 무효 — 리뷰 중 수정, 해소.** 초기 구현은 `directionBarClassNames`에서 `ml-1/2`·`mr-1/2`를 사용했는데 이는 유효한 Tailwind 유틸이 아니라 CSS가 적용되지 않아 순매수·순매도 막대가 같은 위치(좌측)로 렌더됐습니다. 색과 배지로 방향이 구분되므로 접근성·기능 문제는 없었으나 의도된 좌/우 배치가 작동하지 않았습니다. 리뷰 중 순매수를 `ml-[50%]`(중앙 우측), 순매도를 좌측 배치로 수정하고 위젯 테스트 3건·lint 통과를 확인해 해소했습니다.

**S2. market·window 고정값 — 2차 범위에서 허용.** 개요·상세 모두 `market="KR"`·`window="7d"`를 하드코딩합니다. seed·계약이 KR 기준이고 시장/기간 선택 UI는 범위 밖(후속)이라 타당합니다. 다중 시장·기간 지원 시 파라미터화가 필요합니다.

## Questions

**Q1. 금액 정밀도.** `net_value`는 BE에서 Decimal을 문자열로 직렬화합니다. FE가 `parseDecimal`로 파싱하고 `formatMoney`로 표기하며, 파싱 실패 시 "금액 미상"으로 폴백함을 확인했습니다. 순매수/순매도 방향은 별도 `direction` 필드에서 오므로 문자열 금액에 부호 산술을 하지 않습니다. 정밀도 손실 위험이 없습니다.

## Final Recommendation

머지 가능합니다. 핸드오프 요구사항을 항목별로 확인했습니다. 주체별 순매수/순매도의 색+배지 병기, 불일치 신호 표기, availability 대체 지표 안내, Decimal 문자열 포맷(float 미사용), 공용 위젯의 두 화면 재사용(개요 market-wide·상세 topic-scoped), 패널별 독립 query·부분 실패가 모두 확인됩니다.

범위는 지켜졌습니다. 계약에 없는 거래량·공매도 지표를 만들지 않았고 3차 패널·폴링(#266)·시장 선택 UI에는 손대지 않았습니다. Protected Files는 없으며 신규 npm 의존성 추가도 없습니다. 추가된 테스트는 query·adapter(성공·오류·빈 데이터·availability=false·정렬 불일치), 위젯(항목·방향·금액·불일치·fallback), 개요·토픽 상세 페이지의 placeholder 교체·부분 실패를 덮습니다.

Blocking은 없습니다. S1은 리뷰 중 수정으로 해소했고, S2는 2차 범위에서 허용, Q1은 정밀도 처리를 확인해 해소했습니다.
