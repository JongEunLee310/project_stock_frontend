# PR #82 — 판단 통계 카드 실데이터 연동 (feat/decision-log-stats-wiring)

리뷰어: Claude Code (Opus, FE 트랙). 구현: Codex. 브랜치: feat/decision-log-stats-wiring → main.

## Review Summary

설계 73 범위대로 DecisionLogPage 우측 두 카드를 BE `GET /decision-logs/stats` 실데이터로 교체했습니다. `useDecisionLogStats`는 `/decision-logs/stats`를 호출해 `decision_type_counts`/`total`을 `adaptDecisionTypeCounts`로(유형 라벨·count desc 정렬·percent 반올림, total 0이면 percent 0), `recent_reviewed`를 `adaptReviewedDecision`으로(note는 `reason` → `risk_note` → 빈 문자열 우선순위, `reviewedAt`은 `formatKstDateTime`) 매핑합니다. "자주 나온 판단 패턴" 카드는 기존 막대 UI(meter/percent)를 유지하며 stats 패턴으로 렌더하고, "최근 복기 메모" 카드는 제목을 "최근 검토한 판단"으로 바꿔 `recent_reviewed`를 렌더합니다. 두 카드 모두 로딩 시 `Skeleton`, 에러/0건 시 `EmptyState`("집계된 판단이 없습니다." / "검토한 판단이 없습니다.")로 처리합니다. `mockDecisionPatterns`·`mockReviewMemos` import/사용과 `sortedPatterns`/`patternTotal`, 기존 `TODO: BE 미지원` 주석을 제거했고, mock 정의는 `shared/mock`에 남겼습니다.
