## Review Summary

새 알림 관제 API의 FE 클라이언트 기반과 상단 요약 카드를 세우는 첫 FE 조각입니다. BE overview
계약(`GET /api/v1/alerts/overview`)을 `AlertOverviewDto` → `adaptAlertOverview` → `AlertOverview`로
매핑하고(6필드 snake→camel 정확), `alertKeys` 쿼리키 팩토리(`all`/`overview`/`rules(filters)`/
`events(filters)`/`channels`)를 도입해 F2·F3가 재사용할 기반을 만듭니다. `useAlertOverview`
훅과 `AlertSummaryCards` 위젯(활성 규칙·오늘 발생·중요도 높음·일시정지·미읽음 5카드,
loading/error·retry/empty/data 상태)을 추가하고, 사이드바 미읽음 배지를 구 시그널 래퍼 기반
`useUnreadAlertSummary`에서 overview `unreadCount`로 재연결합니다.

기존 관례를 잘 따릅니다: `apiGet` 엔벨로프, DTO→adapter 패턴, `@/shared/ui` 재사용, 중요도
색상은 배지에만 제한. 구 `AlertsPage` 인박스와 `useAlerts`·`useAlertCandidates`·
`useUnreadAlertSummary` 훅은 그대로 두어 병존합니다(F3에서 정리). 사이드바 훅 계약 변경에
따라 `DashboardPage`·`WatchlistPage` 테스트 목을 갱신한 것도 필요한 조치입니다.
