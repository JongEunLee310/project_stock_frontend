## Review Summary

변경된 4개 파일 모두 design-69 범위 안이다: `dto.ts`, `adapters.ts`, `queries.ts`, `PortfolioPage.tsx`. DTO는 `day_change_value`/`day_change_percent`를 `string | null`로 추가하고, 어댑터는 `parseDecimal(...) ?? 0`으로 매핑하며, queries의 빈 포트폴리오 fallback 객체는 갱신된 `PortfolioView` 타입을 충족하도록 두 필드를 보완했다. 페이지는 실데이터에 바인딩된 "일간 변동" `SummaryCard`를 추가한다. `visual="delta"`와 `positive`는 `SummaryCard` 타입 정의(`'wallet' | 'donut' | 'delta' | 'risk'`, `positive?: boolean`)에 **이미 존재하던 props**라 새 prop·visual 타입 추가가 없다. graceful degradation 확인: BE 필드 부재 시 `parseDecimal(undefined) ?? 0` → `0` 표시로 별도 가드 코드가 필요 없다. PortfolioPage의 mock 주석도 `riskExposures`/`aiBriefing`만 잔여 mock으로 정확히 남겼다. 어댑터 테스트는 매핑 케이스와 누락 필드 0 폴백을, PortfolioPage 테스트는 신규 카드의 label/value/percent 단언을 커버한다.
