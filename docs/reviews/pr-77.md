## Review Summary

설계(design-69) 범위 그대로 네 개 파일을 수정했습니다: `dto.ts`, `adapters.ts`, `queries.ts`, `PortfolioPage.tsx`. DTO에 `day_change_value`·`day_change_percent`를 `string | null`로 추가하고, 어댑터에서 `parseDecimal(...) ?? 0`으로 매핑하며, queries의 빈 포트폴리오 기본값 객체에도 두 필드를 채워 갱신된 `PortfolioView` 타입을 맞췄습니다. 페이지에는 실데이터에 바인딩된 "일간 변동" `SummaryCard`를 추가합니다. `visual="delta"`와 `positive`는 `SummaryCard` 타입 정의(`'wallet' | 'donut' | 'delta' | 'risk'`, `positive?: boolean`)에 이미 있던 props라 새 prop이나 visual 타입을 더하지 않았습니다. graceful degradation도 확인했습니다 — BE 필드가 없으면 `parseDecimal(undefined) ?? 0` → `0`으로 표시되어 별도 가드가 필요 없습니다. PortfolioPage의 mock 주석도 `riskExposures`·`aiBriefing`만 잔여 항목으로 남겼습니다. 테스트는 어댑터의 매핑·누락 필드 0 폴백과 신규 카드의 label/value/percent 단언을 모두 커버합니다.

## Final Recommendation

**Approve.**

계약 항목을 모두 충족합니다. DTO 필드 추가, `parseDecimal ?? 0` 폴백 어댑터 매핑, 기본값 객체 갱신, 기존 `delta` visual·`positive` prop을 활용한 "일간 변동" 카드 추가, 잔여 mock만 남기도록 정리한 주석까지 설계대로 구현됐습니다. 테스트는 정상 매핑과 누락 필드 0 폴백을 모두 커버하고, 범위 밖 항목 `aiBriefing`·`riskExposures`는 변경되지 않았음을 확인했습니다.
