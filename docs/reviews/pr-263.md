# PR #263 로컬 리뷰 — 판단 품질 체크리스트 + 유사 판단 표시 (#261)

## Review Summary

판단 기록 재설계 3차 FE의 마지막입니다. 판단 상세에 복기 품질 체크리스트와 유사 과거 판단을 추가합니다. BE `GET /api/v1/decision-logs/{id}/similar`(`project_stock` #365)를 소비합니다.

`features/decision-log`의 `dto.ts`·`queries.ts`에 `useSimilarDecisions(id)` 훅(기존 list-item 어댑터 재사용)을 더했습니다. `widgets/decision-detail/DecisionDetail.tsx`에 두 섹션을 추가합니다: 복기 `process_quality`를 항목별 체크리스트/점수로 중립 표시(복기가 있을 때, `shared/model/processQuality` 라벨 재사용, 없으면 빈 상태)하고, 유사 과거 판단을 경량 목록으로 표시해 항목 클릭 시 해당 판단 상세로 이동합니다.

이번 리뷰는 품질의 중립 표현(확정 진단 금지, 설계 §24), 유사 판단 소비, 빈/로딩 상태를 축으로 봤습니다.
