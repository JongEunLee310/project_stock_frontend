## Suggestions

**S1. `PriceChartCard`의 disabled 탭 두 개에 `id`가 없어 `aria-controls` 연결이 불완전합니다**

활성 탭(`가격`)은 `id="research-price-tab"`을 갖고 `tabpanel`이 `aria-labelledby="research-price-tab"`으로
이를 참조합니다. 반면 `밸류에이션`과 `실적` 탭에는 `id`가 없습니다. 현재는 두 탭이
`disabled`이므로 패널 참조 자체가 없어 런타임 오류가 발생하지는 않습니다. 그러나
ARIA Authoring Practices Guide의 탭 패턴은 모든 `role="tab"` 요소가 대응하는
패널과 `aria-controls`로 연결되거나, 패널이 `aria-labelledby`로 탭을 참조할 것을
권고합니다. 향후 탭을 활성화하는 #149 작업에서 id와 aria-controls를 추가하지
않으면 스크린리더가 패널 소속을 인식하지 못합니다. 현재 범위에서 차단 요인은
아니지만, #149 핸드오프에 이 연결 요건을 명시해 두는 것을 권장합니다.

심각도: 비차단, 후속 이슈(#149) 핸드오프 메모 권장.

**S2. 헤더 밴드 4열 그리드 내 심볼 셀의 `<h2>`가 페이지 제목 `<h1>`과 동일 레벨로 병렬 존재합니다**

페이지 최상단 `<header>` 내 `<h1>`은 `{symbol} 리서치`를 표시하고, `HeaderCard` 내
그리드 첫 번째 셀도 `<h2>`로 심볼을 표시합니다. 심볼은 두 곳에서 각각 렌더링되어,
h1 뒤에 h2(심볼)가 오는 구조가 됩니다. 스크린리더 탐색 시 "NVDA 리서치(h1)" 이후
"NVDA(h2)"가 별도 섹션 헤딩으로 읽혀 혼동을 줄 수 있습니다. 헤더 밴드 심볼 셀은
`<p>` 또는 `<span>`으로 낮추거나, 페이지 `<h1>`이 심볼만 담고 밴드의 심볼을
시각적으로만 표시하는 aria-hidden 처리를 검토할 수 있습니다. 레이아웃 PR 범위
내에서의 선택적 개선입니다.

심각도: 비차단, 접근성 개선 권장.

**S3. `getAllByText('평균 목표주가').length > 0` 단언을 `getByText`로 강화한 것은 타당합니다**

기존 테스트는 `getAllByText`로 복수 매칭을 허용했는데, 이는 차트 카드와 헤더 양쪽에
"평균 목표주가"가 렌더될 때의 잔재입니다. 이 PR에서 차트 카드의 보조 블록이 제거되어
"평균 목표주가"는 메트릭 그리드에 하나만 존재하므로 `getByText`로 강화한 것이 올바른
셀렉터 갱신입니다. 로직 변경이 아닌 실제 렌더 구조를 정확히 반영한 수정입니다.

심각도: 정보 제공(확인 완료).
