# PR #81 — 관심 종목 알림 현황 실데이터 연동 (feat/watchlist-alert-status-wiring)

리뷰어: Claude Code (Opus, FE 트랙). 구현: Codex. 브랜치: feat/watchlist-alert-status-wiring → main.

## Review Summary

설계 72 범위대로 WatchlistPage의 "빠른 알림 설정"(`mockWatchlistAlertSettings`) 카드를 제거하고 실제 alerts 데이터를 쓰는 "알림 현황" 카드로 교체했습니다. `useUnreadAlertSummary`는 `/alerts?status=UNREAD`를 호출해 `meta?.total ?? data.length`로 미읽음 수를, 상위 5건을 `adaptAlert`로 매핑해 최근 알림을 반환하며, `try/catch`로 실패 시 `emptyUnreadAlertSummary`로 흡수합니다. `adaptAlert`는 `alert_type`을 `alertTypeLabels`로 라벨링하고 `message ?? ''`로 방어하며, `title`을 BE 미전송 시 `symbol`+유형 라벨로 파생합니다. 카드는 로딩 시 `Skeleton`, 0건 시 `EmptyState`("새 알림이 없습니다."), 그 외 최근 알림 목록(상태·유형 배지, 종목, 상대 시각)을 렌더합니다. `mockWatchlistAlertSettings` import/사용은 제거하고 정의는 `shared/mock`에 남겼으며, `mockWatchlistObservations`는 유지했습니다.

## Blocking

None.

## Suggestions

**S1 · `adaptAlert`에 `createdAtIso` 필드 추가**

상대 시각 계산을 위해 `Alert`에 원본 ISO 문자열 `createdAtIso`를 더했습니다. 설계 72에 명시되진 않았으나 카드의 상대 시각 표시를 위한 합리적 보강이며 기존 소비자에 영향이 없습니다. 비차단 사항입니다.

**S2 · 상대 시각 포매터가 페이지 내부 전용**

`formatRelativeTime`이 WatchlistPage 안에 정의됐습니다. 추후 다른 화면에서 동일 표기가 필요하면 `shared/lib/format`로 승격을 검토하면 좋겠습니다. 현재 단일 사용처라 비차단입니다.
