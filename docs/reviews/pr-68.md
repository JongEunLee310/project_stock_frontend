## 배경

이슈 #67 통합 점검에서 코드로 검증된 P0 FE 계약 불일치 3건. 기본 브랜치 변경(레포 설정)은 코드 범위 밖이라 제외.

## 정확성

- **thesis asset_id** — `research/queries.ts` queryFn 내 이미 확보한 `assetId`를 `/theses/latest?asset_id=`로 전달. 숫자 id라 인코딩 불요. BE 필수 파라미터 충족. ✔
- **signals expand=asset** — `useSignals` 목록 호출에 항상 `expand=asset`, `asset_id` 동반 시 `?asset_id=…&expand=asset`. adapter는 기존 `asset.symbol`/`asset.name` fallback 보유 → 추가 변경 최소, `UNKNOWN` 해소. ✔
- **score 스케일** — BE 계약 직접 확인(`SignalCreate.score=Field(ge=0,le=100)`, `SignalResponse.score:int`, BE 테스트 78/80/82/90 정수). FE `* 100` 제거 후 `normalizeScore`(clamp+round) 도입, ring offset·표시 모두 동일 함수 사용 → 일관성 확보. ✔
- 도메인 타입/envelope/에러 매핑 무변경. 상세(`/signals/{id}`)는 의도적으로 손대지 않음(범위 준수). ✔
