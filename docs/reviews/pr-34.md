# PR #34 Local Review — Stock Research Detail 페이지 (task-012 / 이슈 10)

## Review Summary

`ResearchPage`를 플레이스홀더에서 시안 기반 실제 화면으로 교체. 헤더 카드(지표 타일·AI 스탠스 박스),
가격 영역(탭·기간 프레임 + SVG 스파크라인), AI 브리핑, 핵심 리스크, 뉴스·공시 요약, 촉매 타임라인,
의사결정 체크리스트, 내 메모를 구성했다. 시안의 풍부한 필드를 담도록 도메인·Mock을 확장(Part A)하고
그 위에 페이지를 구현(Part B)했다. 설계 `docs/designs/10-research-detail-page.md`, 핸드오프
`.codex/tasks/task-012-research-detail-page.md`와 구조가 일치한다.

검토 항목:

- **확정 결정 준수(차트 경계)**: 가격 영역은 탭(가격/밸류에이션/실적)·기간(1D~5Y) 프레임 + `pricePoints`
  **SVG `polyline` 스파크라인**(`role="img"` + `aria-label`)까지만. 캔들·거래량·비교지수·차트 라이브러리는
  도입하지 않음 → **이슈 19** 경계 준수. 차트 라이브러리 의존성 추가 없음(`pnpm build` 모듈 75개, 라이브러리
  미증가).
- **도메인·Mock 확장 정확성**: 신규 enum `NewsCategory`/`CatalystCategory`는 `as const` + 파생 union 패턴
  (`stockStatus.ts` 선례). `StockResearch`(+9 필드)·`NewsItem`(+category)·`CatalystItem`(+category)·
  `ChecklistItem`(+description)가 설계 표와 정확히 일치. **필수 필드 추가에도 `mockStockResearch` 4심볼
  (NVDA/AAPL/TSLA/MSFT)·뉴스·촉매·체크리스트 전수 채움** → `satisfies`·`typecheck` 통과(파괴적 변경 회피).
- **완료 조건 충족**: `/research/NVDA`(및 MSFT 등) 접근·기본 정보·AI 스탠스(신뢰도 65%)·핵심 리스크 3건+·
  체크리스트 체크 가능(진행도 1/2→2/2)·메모 입력 UI 모두 테스트로 확인.
- **공통 컴포넌트 재사용**: `Card`/`Badge`/`Button`/`Input` 재사용. 상태·위험도는 기존 `Badge`(StockStatus·
  RiskLevel) 매핑. 카테고리는 `Badge`에 **`tone` variant**(neutral/accent/info/warning)를 더해 표현 —
  기존 status/riskLevel 오버로드는 그대로(하위 호환), 카테고리별 색상 인라인 복제 없이 일반 톤으로 처리.
- **로컬 상태**: 체크리스트 토글·메모 입력·관심종목은 `useState` 제어 컴포넌트. 서버 영속화 없음(설계대로).
- **미발견 처리**: 미지원 심볼은 "데이터를 찾을 수 없습니다" 빈 상태 + 워치리스트 복귀 링크.
- **타임존 안전**: 시간 표시는 표시 문자열(`priceAsOf`)·날짜 문자열(YYYY-MM-DD) 위주. 테스트는 종목·상태·
  숫자·라벨로 단언해 시간 문자열 단언을 피함 → CI(UTC) 안전.
- **테스트 정합 갱신**: 플레이스홀더 제목("NVDA Research")이 실제 제목("NVDA")로 바뀌어 `App.test.tsx`·
  `WatchlistPage.test.tsx`의 헤딩 단언을 갱신(핸드오프에서 명시 허용). `App.test`는 스파크라인 `role="img"`
  존재까지 추가 단언.

로컬 검증: `format:check`·`lint`·`typecheck`·`TZ=UTC pnpm test`(46/46, ResearchPage 7건 신규)·`build`
모두 통과.

  차이가 있다. 사용자와 **"빠르게 구현 후 후속 수정"** 합의됨 → 시각 정밀 반영은 별도 후속 라운드에서 진행.
- **카테고리 톤 토큰화**: `badgeToneClassNames`의 info/warning이 원시 Tailwind 색(`sky-400`/`amber-400`)을
  사용한다. 다른 상태/위험도 배지는 `@theme` app-* 토큰 기반이므로, 일관성을 위해 카테고리 톤도 토큰화
  (`src/index.css` @theme 추가) 후 치환하면 좋다(본 PR 차단 아님).
- **차트 영역 후속**: 탭·기간 버튼이 현재 시각 프레임(가격 외 비활성)이다. 이슈 19에서 캔들·거래량·비교지수·
  기간 전환과 함께 활성화하면 자연스럽다.
- **Select 공통화(이월)**: PR #32·#33에서 제기된 `shared/ui` 공통 `Select` 승격 후보는 여전히 유효(이번
  페이지 영향은 없음).
