# PR #208 — 리서치 헤더 로고 한국 종목 후보 적용 (fix/205-research-header-logo)

리뷰어: Claude Code (Sonnet, VFF). 구현: Codex. 브랜치: fix/205-research-header-logo → main. 관련: 이슈 #205, 핸드오프 `.codex/tasks/task-075-research-header-logo.md`.

## Review Summary

이슈 #205가 지적한 문제는 `ResearchPage.tsx`의 헤더 로고가 심볼 원문을 그대로 parqet URL에 사용해 6자리 한국 종목 심볼(예: `005930`)에서 404가 나고 이니셜 fallback으로 떨어지는 것이었습니다. 이번 PR은 새 로직을 추가하지 않고 이미 `WatchlistPage`에서 쓰이던 `StockLogo` 컴포넌트를 리서치 헤더에도 그대로 재사용해 문제를 해결합니다.

`StockLogo.tsx`의 내부 함수 `getLogoCandidates`는 그대로 유지됩니다. market이 `KOSPI`/`KOSDAQ`이면 각각 `.KS`/`.KQ` suffix를 붙이고, market 정보가 없어도 심볼이 6자리 숫자면 `.KS` → `.KQ` 순으로 후보를 시도합니다. 후보 배열이 소진되면(`candidate == null`) `img` 자체를 렌더링하지 않아 뒤에 깔린 이니셜 `mark.label`만 보이는 구조라, 모든 후보 실패 시에만 이니셜 fallback으로 자연스럽게 떨어집니다.

`ResearchPage.tsx`의 `HeaderCard`는 기존에 갖고 있던 `isLogoLoadFailed` 로컬 상태와 인라인 `img`/fallback div 분기를 통째로 제거하고, `StockLogo`에 새로 추가된 `imageClassName` prop으로 헤더 전용 크기(`h-14 w-14`, `object-contain p-1.5`)만 얹었습니다. 핸드오프가 명시한 "중복 구현을 남기지 말 것" 조건대로 후보 로직의 두 번째 구현체를 만들지 않고 className 확장만으로 헤더 요구사항을 흡수한 선택입니다.

None.

## Suggestions

**S1 · parqet URL의 `?format=png` 쿼리 파라미터가 빠짐(비차단, 검증 완료)**

기존 `ResearchPage.tsx` 코드와 이슈 본문 예시는 `?format=png`를 붙인 URL을 사용했지만, 재사용된 `StockLogo`는 애초부터 이 파라미터 없이 `https://assets.parqet.com/logos/symbol/${candidate}` 형태로 요청합니다. 실제로 `curl`로 확인한 결과 `005930.KS`, `NVDA` 모두 `?format=png` 유무와 무관하게 200을 반환해 로고 표시에는 영향이 없습니다. `StockLogo`가 이미 `WatchlistPage`에서 이 형태로 쓰이고 있던 기존 동작이라 이번 PR이 새로 만든 차이는 아니며, 후속 조치가 필요하지 않은 참고 사항입니다.

## Scope Control

- 소스 변경은 `src/shared/ui/StockLogo.tsx`(`imageClassName` prop 추가)와 `src/pages/ui/ResearchPage.tsx`(헤더 로고를 `StockLogo`로 교체) 두 파일로 한정됩니다.
- `getLogoCandidates`의 후보 규칙(market 기반 suffix, 6자리 심볼 KS→KQ fallback) 자체는 수정 없이 그대로 재사용됩니다.
- `WatchlistPage.tsx`에서의 `StockLogo` 두 호출부는 diff에 포함되지 않았고, `imageClassName`이 optional이라 미전달 시 기존 클래스만 적용되므로 회귀가 없습니다. `corepack pnpm run test` 실행 결과 `WatchlistPage.test.tsx` 32건도 모두 통과해 이를 뒷받침합니다.
- 종목 전환 시 상태 리셋은 이번 PR 이전부터 `HeaderCard` 호출부에 있던 `key={research.symbol}`으로 이미 보장되고 있었고, 이번 PR은 `StockLogo`에도 `key={`${research.symbol}:${research.market ?? ''}`}`를 추가해 market만 바뀌는 경우까지 후보 인덱스가 리셋되도록 이중으로 보강했습니다.
