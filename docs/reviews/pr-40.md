# PR #40 Local Review — 판단 기록 페이지 시안 충실화 (이슈 11)

## Review Summary

이슈 11 판단 기록(`/decision-log`) 페이지를 시안 충실도 우선으로 다듬었다. 대시보드(PR #37)·관심 종목
(PR #38)·시그널(PR #39)과 동일한 시안 충실화 기조로 셸 톤(`cockpit-*` 토큰)을 통일하고 KPI 카드·새 판단
기록 폼·로그 테이블 헤더·패턴/복기 패널 표현을 시안에 맞췄다. **도메인/Mock/테스트 변경 없는 페이지 표현
레이어만의 변경**이다. 설계 `docs/designs/11-decision-log-page.md`에 "시안 충실화 재결정" 섹션을 추가해
구현과 일치시켰다.

검토 항목:

- **셸 톤 `cockpit-*` 토큰 통일**: 폼·KPI 카드·패턴/복기 패널의 `app-*`를 `cockpit-*`로 교체. 단, 테이블 셀
  렌더(날짜/이유/재검토 muted 텍스트·종목 링크) `app-*` 4곳은 잔여(Suggestion 참조). 대시보드/관심 종목/
  시그널 라운드와 톤 일관.
- **KPI 카드 아이콘 + tone 재구성**: 라벨/값 세로 나열 → 좌측 원형 아이콘(▤/▦/◉/△, `aria-hidden`) + 우측
  라벨·값·설명 가로 배치. tone(blue/slate/amber/rose) 의미색. "관망 유지"·"리스크 증가 검토" 설명은
  비율(`Math.round(count/total*100)%`) 동적 계산 — 정적 자리표시 아님. "이번 주 기록" 설명만 정적.
- **새 판단 기록 폼 가로 라벨 — 테스트 `aria-label` 보존 확인**: `FieldLabel`로 라벨·입력 가로 정렬. 가시
  라벨은 시안 문구로 갱신("판단 유형"·"다음 확인 날짜"·"메모 (선택)")했으나, 테스트가 의존하는
  `aria-label`(`판단유형`·`재검토 일정`)을 select/Input에 보존해 회귀 없음. 메모 500자 카운터 추가, 인지
  리스크 3열 그리드 + "(복수 선택 가능)" 안내.
- **로그 테이블 헤더 인라인 필터 바**: 비활성 일별/기간 `select` 2종 제거 → 헤더 제목 + info 배지 + "필터"
  버튼(동작 없는 자리표시). `Table`은 `rounded-none border-0 bg-transparent`로 카드에 합쳐 표현 — 공통
  `Table<DecisionLog>` 재사용·페이지네이션·`aria-label` 유지.
- **패턴/복기 패널 충실화 — 접근명 보존 확인**: 패턴 막대 색 `app-accent` → `blue-500`, 비율 표기
  "건수·%" → "% (건수)"(`role="meter"` `aria-label` 유지). 복기 메모 카드형(테두리 + muted 배경), 날짜를
  제목 앞에 배치하고 "복기 보기 ›" 링크 — 접근명은 `aria-label="복기 보기"`로 보존해 테스트 회귀 없음.
- **타임존 안전**: 시간 포매터 `timeZone: 'Asia/Seoul'` 고정 유지(이번 PR 무변경). KPI·패턴은 고정 mock
  파생이라 현재 시각 비의존. `TZ=UTC pnpm test`(58/58) 로컬 통과로 확인.
- **공통 컴포넌트 재사용**: `Card`/`Button`/`Input`/`Table`/`Badge` 재사용 유지. 종목 링크
  `/research/:symbol`. 네이티브 다이얼로그 없이 인앱 표현.

## Suggestions

- **테이블 셀 렌더 잔여 `app-*` 토큰 4곳**: 페이지 대부분은 `cockpit-*`로 통일했으나 `columns`의 셀 렌더
  (날짜/시간·판단 이유·재검토 일정 muted 텍스트, 종목 링크 hover/focus)가 여전히 `app-*` 토큰을 쓴다.
  관심 종목(PR #38)의 `RowMenu` 잔여와 동일 성격 — 셸/페이지 톤 일관성을 위해 `cockpit-*` 통일 권장(비차단).
- **정적 자리표시**: "이번 주 기록" 설명 "지난 주 대비 +27%"와 헤더 "필터" 버튼(동작 없음)은 자리표시다.
  관심 종목(PR #38)·시그널(PR #39) 리뷰 반영처럼 실제 파생/비활성 표기로 명확화하거나 실데이터 연동 시
  일괄 처리 권장(비차단).
- **원시 색/리터럴 토큰화(이월)**: KPI tone(blue/slate/amber/rose), 패턴 막대 `blue-500`, 저장 버튼
  `blue-600`, 복기 강조 `blue-300`이 원시 Tailwind 값이다. 의미 토큰화는 후속(이전 라운드와 동일 이월).
