## 발견 사항

1. **[Blocking → 수정함] API path `/api/v1` 더블 프리픽스.** 신규 `queries.ts`가
   `/api/v1/dashboard/summary` 등 절대 prefix를 포함했으나, 기존 규약은 `authApi`
   (`/auth/login`, `/auth/me`)·client(`/auth/refresh`)가 prefix 없이 호출하고
   `VITE_API_BASE_URL`이 `/api/v1`을 보유하는 형태다. 둘을 함께 두면 신규 호출이
   `…/api/v1/api/v1/…`로 깨진다. query 훅을 모킹한 페이지 테스트로는 잡히지 않았다.
   → 신규 path에서 `/api/v1` 제거로 규약 일치, 재검증 통과.
2. **[경미] `WatchlistAssetRow.isFavorite: true` 하드코딩.** watchlist 항목은 정의상
   관심종목이라 동작상 무해하나, 출처 없는 값의 하드코딩이므로 후속에서 제거 또는 주석 권장.
3. **[경미·스코프] `src/features/README.md` 신규 생성.** 핸드오프에 없던 파일이나 FSD 레이어
