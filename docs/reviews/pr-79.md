## Review Summary

설계(design-70) 범위대로 다섯 파일을 수정했습니다: `dto.ts`, `adapters.ts`, `queries.ts`, `PortfolioPage.tsx`와 두 테스트. DTO에 신규 `RiskExposureDto`와 `risk_exposures?: RiskExposureDto[] | null`을 추가하고, `adaptPortfolioSummary`에서 `dto.risk_exposures ?? []`를 `PortfolioView.riskExposures`로 매핑합니다. `level` 변환은 `toRiskLevel`에서 `HIGH`→`높음`, 그 외(`MEDIUM` 포함 모든 값)→`중간`으로 처리해 계약의 방어적 기본값과 일치하고, `id`는 BE `code`를 사용합니다. 기존 도메인 타입 `PortfolioRiskExposure`를 재사용해 신규 타입을 만들지 않았습니다. queries의 빈 포트폴리오 fallback에 `riskExposures: []`를 더해 graceful degradation을 유지하며, BE 미배포 시 `?? []`로 흡수됩니다. 페이지는 카드를 `portfolio.riskExposures`로 렌더하고 0건일 때 빈 상태 문구를 표시하며, mock 주석은 `aiBriefing`만 남겼습니다.
