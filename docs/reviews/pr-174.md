## Review Summary

설계 문서 §3의 범위대로 `NewsDisclosurePanel`에 `isExpanded` 상태를 추가하고,
`NewsDisclosureList`에 `variant: 'compact' | 'full'` prop을 도입했습니다. 접힘
기본 상태에서는 활성 탭의 최신 3건만 `visibleItems = items.slice(0, 3)`으로
잘라 compact variant로 렌더하고, `items.length > 3`일 때만 카드 하단에 "더 보기 ›"
토글을 노출합니다. compact variant는 `[카테고리 배지] 제목 한 줄(truncate) +
출처 · 시각`만 렌더하고 요약 문단과 감성/중요도 배지는 렌더하지 않으며, 항목
테두리 박스 대신 `divide-y divide-app-border` 구분선으로 가볍게 바뀌었습니다.
truncate가 적용된 `<a>`에는 `title={item.title}`이 붙어 전체 제목이 접근 가능
합니다. 탭 전환 핸들러를 `selectTab`으로 통합해 클릭 시 `isExpanded`를 항상
`false`로 되돌리므로 설계 §3의 "탭 전환 시 접힘 초기화" 요건을 충족합니다.

토글 버튼은 `aria-expanded`를 `isExpanded` 값과 동기화하고, 항목이 3건
이하이면 `hasMoreItems`가 `false`가 되어 버튼 자체가 렌더되지 않습니다. 펼친
상태(`variant="full"`)는 기존 요약·감성/중요도 배지 구성을 그대로 유지해 회귀가
없습니다. `visibleItems`는 원본 `items` 배열의 부분 슬라이스이므로 `key={item.id}`가
그대로 유지되어 슬라이스에 따른 키 충돌이나 불필요한 리마운트는 없습니다.
