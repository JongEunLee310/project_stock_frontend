## Suggestions

1. `assets.parqet.com` CDN이 미등록/오타 심볼에 대해 404가 아니라 200
   placeholder 이미지를 반환할 가능성을 실제로 검증하지 못했습니다. 만약
   그렇다면 `onError`가 발동하지 않아 의도치 않은 placeholder 로고가
   이니셜 대신 노출될 수 있습니다. 이번 리뷰 범위에서 확정할 수 없는
   외부 서비스 동작이라 blocking으로 올리지는 않지만, 실제 미등록 심볼
   응답을 한 번 확인해 설계 문서 Risks 섹션에 반영해두면 좋겠습니다.
2. `<img>`에 `referrerPolicy`가 지정되어 있지 않습니다. 최신 브라우저
   기본값(`strict-origin-when-cross-origin`)에서는 cross-origin 요청 시
   경로까지는 노출되지 않지만 origin(도메인)은 CDN에 전달됩니다. 리스크는
   낮아 blocking은 아니며, 필요시 `referrerPolicy="no-referrer"` 추가를
   검토할 수 있습니다.
