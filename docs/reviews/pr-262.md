# PR #262 로컬 리뷰 — 판단 분석 화면 (#260)

## Review Summary

판단 기록 재설계 3차 FE입니다. 반복 판단 패턴과 품질을 시각화하는 판단 분석 화면을 추가하며, BE `GET /api/v1/decision-logs/analytics`(`project_stock` #364)를 소비합니다.

`features/decision-log`의 `dto.ts`·`adapters.ts`·`queries.ts`에 analytics 타입과 `useDecisionAnalytics` 훅을 더하고, `shared/model/processQuality.ts`에 품질 항목 라벨을 추가했습니다. `widgets/decision-analytics/DecisionAnalytics.tsx`가 유형·확신 분포, 반대 근거 작성률, 확신별 복기 결과, 위험 태그 빈도, 재검토 준수율, process_quality 항목별 평균을 시각화하고, `pages/ui/DecisionAnalyticsPage.tsx`가 `/decision-log/analytics` 라우트에 이를 배치합니다. 판단 기록 화면에 분석 화면 진입점을 두었습니다.

이번 리뷰는 BE 지표 소비, 중립적 편향 표현(확정 진단 금지), enum 라벨화, 빈/오류 상태를 축으로 봤습니다.

## Blocking

None.

## Suggestions

**S1. 반대 근거 작성률 등 편향 지표의 중립 표현 — 원칙 준수 확인.** 반대 근거 작성률·확신별 성과 같은 지표는 확정 진단 어조 없이 정량 지표/점검용으로 표시됩니다(스펙 §16). 화면 문구가 "편향이다"라고 단정하지 않고 비율·빈도로 제시함을 확인했습니다. 원칙에 맞습니다.

## Questions

**Q1. 0건·빈 분포에서 안전한가.** analytics가 0건일 때 빈 상태를 렌더하고, 분포·평균이 없을 때 오류 없이 처리함을 확인했습니다. 테스트가 0건·빈 상태·로딩·오류를 덮어 해소됐습니다.
