# PR #31 Local Review — Watchlist 관심 종목 페이지 (task-008 / 이슈 8)

## Review Summary

`WatchlistPage`를 플레이스홀더에서 실제 화면으로 교체. `mockStocks` 기반으로 요약 카드,
검색·시장·뉴스 위험도 필터·정렬, 관심 종목 테이블(상태/위험도 Badge·행 액션·리서치 이동)을 구현.
설계 기록 `docs/designs/8-watchlist-page.md`와 일치한다.

검토 항목:

- **완료 조건 충족**: NVDA/AAPL/TSLA/MSFT 표시, 상태·변화율·뉴스 위험도·밸류에이션·AI 판단 컬럼,
  필터 UI 반영, 심볼 링크·행 액션으로 `/research/:symbol` 이동.
- **공통 컴포넌트 재사용**: `Table`/`Badge`/`Button`/`Input`/`Card`를 그대로 사용. 신규 공통 프리미티브
  미신설. 상태→`Badge status`, 뉴스 위험도→`Badge riskLevel`로 union 매핑 재사용.
- **상태·파생**: 검색/시장/위험도/정렬키/방향을 `useState`로, 표시 행을 `useMemo`로 파생. 원본 mock
  불변(`[...stocks].sort`). 필터 옵션은 mock(`markets`)·도메인 enum(`riskLevels`)에서 파생.
- **이동**: 심볼은 `Link`(우클릭/새 탭 등 자연스러운 네비게이션), 행 액션 버튼은 `useNavigate`. 둘 다
  `getResearchPath`로 경로 일원화. 네이티브 다이얼로그 미사용(컨벤션 준수).
- **접근성**: 테이블 `aria-label="관심 종목"`, 필터는 `<label>`로 연결, 변화율 색상은 텍스트와 병행.
- **포맷·표기**: 통화 `Intl.NumberFormat`(USD), 변화율 부호 표시(`signDisplay: 'always'`).

로컬 검증: `format:check`·`lint`·`typecheck`·`test`(28/28)·`build` 전부 통과.

## Suggestions

- 필터/정렬 `<select>`는 네이티브 요소를 `Input` 스타일에 맞춰 인라인했다. 현재는 1개 페이지 전용이라
  타당(과도한 추상화 회피). 다른 페이지(Signals 등)에서 동일 셀렉트가 재등장하면 그때 `shared/ui`
  공통 Select로 승격할 것(재사용 신호 2곳 기준, 컨벤션).
- 변화율 색상에 `emerald-300`/`rose-300` Tailwind 팔레트 직접 사용. 앱 디자인 토큰(`app-*`)에 상승/하락
  의미색이 생기면 토큰으로 치환 고려(현재 토큰 부재라 차단 사유 아님).
- 행 액션이 "리서치 보기" 단일이라 심볼 링크와 기능 중복. MVP 의도(완료 조건의 행 액션)로 수용하되,
  후속에서 결정 기록 등 액션이 늘면 메뉴화 고려.
