## Review Summary

리서치 상세 페이지의 하단 배치를 조정하는 변경입니다. `git diff main...HEAD`
기준 `src/pages/ui/ResearchPage.tsx` 한 파일에서 3줄이 바뀝니다.

첫째, `RiskPanel`을 감싸는 `Card`(890행)에 `className="h-full"`이 추가됩니다.
둘째, 해당 `Card`가 `aside`(1548행) 안에서 제거되어 `aside`에는
`AI briefing` 카드 하나만 남습니다. 셋째, `반대 관점`(`CounterViewPanel`)·
`데이터 커버리지`(`ResearchCoveragePanel`)가 있던 행의 grid가
`md:grid-cols-2`에서 `md:grid-cols-2 xl:grid-cols-3`로 바뀌고, 같은 행에
`RiskPanel`이 세 번째 카드로 추가됩니다.

section deep-link 앵커(`researchSectionIds.risks`)는 `RiskPanel`을 감싸는
`Card`에 그대로 남아 있어(890행) DOM 위치 이동과 무관하게 동작합니다.
`researchSectionIds`를 통해 스크롤하는 핸들러(1326행)도
`document.getElementById(researchSectionIds[section])`로 id만 참조하므로
회귀 위험이 없습니다.

`h-full` 추가는 같은 행의 기존 두 카드(`CounterViewPanel`, 934행 /
`ResearchCoveragePanel`, 976행)가 이미 `className="h-full"`을 쓰고 있던
패턴과 일치합니다. 세 카드의 내용 길이가 서로 달라도(반대 관점 항목 수,
커버리지 축 수, 리스크 개수) grid 행 안에서 카드 높이가 맞춰지므로 시각적
정렬이 유지됩니다.

`md`(2열) 구간에서는 세 번째 카드인 `RiskPanel`이 다음 행으로 내려가
2열 중 왼쪽 칸만 차지하고 오른쪽 칸은 비게 됩니다. 이는 3개 항목을
2열 grid에 배치할 때 구조적으로 발생하는 배치이며, 이슈 #177에서
명시적으로 요청한 "xl에서 3열" 배치의 부산물입니다. 바로 아래 행
(뉴스·공시 / 캐탈리스트 / 체크리스트 / 메모, 1557행)은 4개 항목을
`md:grid-cols-2 xl:grid-cols-4`로 배치해 `md`에서 2+2로 고르게 채워지는
것과 대비되지만, 이번 PR의 범위는 이슈에 명시된 3열 배치 자체이고 `md`
구간의 홀수 배치는 후속 조정 없이도 기능·접근성에 영향을 주지 않는 시각적
사항이라 blocking으로 보지 않습니다.

`aside`는 이제 `AI briefing` 카드 하나만 남아 `PriceChartCard`(차트) 대비
짧아집니다. 행 컨테이너가 `xl:items-start`를 쓰므로 원래도 aside와
차트는 높이를 서로 맞추지 않는 독립 크기였고(변경 전에도 `stretch`가
아니었음), 카드 하나가 줄어든 만큼 aside가 더 짧아지는 정도의 차이입니다.
`h-full`을 적용할 대상이 aside 쪽 형제 카드가 아니므로 새로운 레이아웃
깨짐은 없으며, 브리핑 카드 아래 여백이 커지는 시각적 결과는 이슈 #177에서
사용자가 이미 확인하고 요청한 배치 의도(aside는 브리핑만 유지)와
일치합니다.
