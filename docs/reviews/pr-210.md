## Review Summary

리서치 목록을 BE `GET /api/v1/research-queue` 단일 요청으로 재구성한 PR입니다.
기존 자산 목록 + 종목별 research-summary N+1 조회(`useResearchList`)가 제거되고,
요약 4타일·필터 칩 5종·확장 컬럼·서버 페이지네이션이 설계 §2·§3대로 구현되었습니다.

- dto가 BE 계약 필드(스네이크 표기·nullable)와 1:1로 일치함을 spec 문서와 대조해
  확인했습니다. 필터 값 4종도 BE 허용값과 일치합니다.
- 상태 6종(PENDING_ANALYSIS 포함) 라벨·tone 매핑이 설계 §2 표와 일치하고,
  미매핑 값은 '—'와 neutral tone으로 폴백해 enum 원문이 노출되지 않습니다.
- `completeness_pct`는 0–100으로 클램프되고 비정상 값(NaN 등)은 0으로
  방어됩니다. `last_updated_at`은 기존 KST 포맷 관례를 재사용합니다.
- `useResearchList`·`adaptResearchListRow`의 잔존 참조가 없음을 grep으로
  확인했습니다.
- `BadgeTone`에 `danger`·`success`가 additive로 추가되었고 기존 tone의 클래스는
  변경되지 않아 다른 화면 회귀가 없습니다.
