## Review Summary

관심 종목 KPI 카드 4장의 아이콘 개편(#127)을 구현하는 PR입니다. 설계 문서
(`docs/designs/127-kpi-card-icons.md`) Decisions를 그대로 따릅니다.

핵심 확인 사항:

- react-icons 5.7.0을 dependencies에 추가하고 `react-icons/lu`(Lucide) 서브패스에서
  네임드 import만 사용합니다. Vite 빌드에서 tree-shaking 대상이므로 번들 영향은
  사용한 4개 아이콘으로 제한됩니다.
- 글리프 배열(`summaryIcons`)과 원형 칩 클래스 배열(`summaryIconClassNames`)을
  `summaryCardIcons`(아이콘 컴포넌트 + 텍스트 색) 하나로 통합하고, 신규
  `SummaryCardTitle` 컴포넌트가 4개 카드 헤더를 공통 처리합니다. 우상단 원형 칩이
  제거되고 아이콘이 제목 왼쪽 글머리 위치로 이동했으며, 기존 색상 코딩
  (blue-300/rose-300/amber-200/emerald-200)은 아이콘 텍스트 색으로 유지됩니다.
- 아이콘 매핑은 이슈 요구와 일치합니다: 전체 관심 종목 `LuBookmark`, 위험 증가
  종목 `LuTriangleAlert`(고평가 배지 indicator `⚠︎`와 동일 계열), 추가 리서치
  필요 `LuSearch`, 신규 매수 여력 `LuHistory`.
- 아이콘은 `aria-hidden="true"` 장식 요소로 유지되어 접근성 트리 변화가 없고,
  카드 제목 텍스트·값·SummaryVisual 등 나머지 구조는 변경되지 않았습니다. KPI
  카드 외 영역의 글리프(검색 `⌕`, 정렬 `↕` 등)는 범위대로 유지됩니다.
- 테스트 — KPI 카드 제목 4개 각각에서 svg 아이콘이 `aria-hidden`으로, 제목
  텍스트보다 앞(firstChild)에 렌더링됨을 단언하는 케이스가 추가되었고 기존
  테스트 약화가 없습니다.
