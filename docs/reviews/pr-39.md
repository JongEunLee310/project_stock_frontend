# PR #39 Local Review — 시그널 페이지 시안 충실화 재구현 (이슈 9)

## Review Summary

이슈 9 시그널 페이지를 시안 충실도 우선으로 재구현했다(PR #33 1차 구현 후 시안 재대조). 대시보드
(PR #37)·관심 종목(PR #38)과 동일한 시안 충실화 기조로 미니 시각요소(`recharts`)·셸 톤(`cockpit-*`
토큰)을 맞추고, 카드/우측 레일 인터랙션을 충실화했다. 설계 `docs/designs/9-signals-page.md`에
"시안 충실화 재결정" 섹션을 추가해 구현과 일치시켰다.

검토 항목:

- **신뢰도 표시 CSS 막대 → 원형 링(`ConfidenceRing`)**: 인라인 SVG 원형 진행 링(`role="meter"`,
  `aria-valuemin/max/now`)으로 카드 헤더 우측 배치. 위험 증가=적색/그 외 emerald. 차트 라이브러리가
  아닌 자체 SVG라 결정성 영향 없음. 1차 설계의 "CSS 막대바"를 시안대로 갱신.
- **카드 1개월 추이 `recharts` 스파크라인 도입(이전 "스파크라인=이슈 19, 범위 밖" 뒤집음)**: 카드 하단
  `LineChart` + 1M 등락(±%). 폭은 `ResizeObserver`로 컨테이너 폭 측정(SSR/비지원 환경 폴백 100),
  `height` 고정·`isAnimationActive={false}`로 결정성 유지. `role="img"` + `aria-label`. 대시보드/관심
  종목과 라이브러리 사용 통일. 이슈 19 경계는 캔들·거래량 등 본격 분석 차트 기준으로 재정의.
- **요약 카드 4종 → 5종**: "총 시그널" 카드 추가 + 상태별 4종. 상태 개수는 `mockSignals` 파생 집계
  유지(`useMemo` reduce). 총 시그널 `128건`·전일 대비 `+12건`·`detail` 퍼센트는 정적 자리표시.
- **우측 레일 충실화**: 우선순위 패널(`priority` 정렬, 신뢰도 델타 ▲/▼ vs `previousConfidence`)·최근
  변경 패널(`updatedAt` 정렬, `previousStatus → status` 전이). 그리드 테이블형 레이아웃.
- **타임존 안전**: 시간 포매터 `timeZone: 'Asia/Seoul'` 고정. 정렬은 고정 mock `confidence`/`priority`/
  `updatedAt` 기준이라 현재 시각 비의존. `TZ=UTC pnpm test`(58/58) 로컬 통과로 확인.
- **`mockStocks` 6 → 8종(AMD/META)·`mockSignals` 2건 교체 — 공유 회귀 확인**: 관심 종목은 전체
  `mockStocks` 표시라 8행이 되지만 푸터·페이지네이션이 동적이라 회귀 없음. 대시보드는 `slice(0,4)`라
  무영향. 전체 58/58 유지로 회귀 없음 확인.
- **공통 컴포넌트 재사용**: 상태 `Badge`, `Card`/`Button`/`Input` 재사용. 종목 링크 `/research/:symbol`.
  카드 액션은 네이티브 다이얼로그 없이 버튼/네비게이션.

## Suggestions

- **정적 자리표시값**: "총 시그널 128건"·전일 대비 "+12건"·요약 퍼센트(42.2% 등)·"알림 설정" 버튼은
  동작 없는 하드코딩 표시값이다. 관심 종목(PR #38) 리뷰 반영처럼 실제 카운트 파생 또는 비활성 표기로
  자리표시임을 명확화하는 편을 권장(비차단). 특히 "총 시그널 128건"은 실제 로드 6건과 괴리.
- **`signalVisuals` 비주얼 메타의 도메인 분리**: `companyName`·`oneMonthChange`·`previousStatus/Confidence`·
  `sparkline`이 페이지 로컬 상수에 하드코딩돼 `mockSignals`(도메인)와 분리돼 있다. 시안 표현 전용으로는
  합리적이나, 실제 시계열 연동 시 도메인/파생 이전 검토 필요. previousStatus/Confidence는 "최근 변경"·
  우선순위 델타의 근거값이므로 향후 도메인에 둘지 결정 권장.
- **신뢰도 링/스파크라인 폭 측정**: `ConfidenceRing`은 고정 SVG라 무관하나, `SignalSparklineChart`는
  `ResizeObserver` + state로 폭을 측정한다. 컴팩트 차트 폭 처리 방식이 관심 종목(고정 `width`)·시그널
  (측정 `width`)으로 갈린다. 반응형 요구가 다르므로 의도된 차이지만, 공통 스파크라인 추출 시 두 방식
  중 하나로 수렴 검토.
- **원시 색/리터럴 토큰화(이월)**: 등락 emerald/red, 강조 sky/amber/blue/orange, 신뢰도 링 색이 원시
  Tailwind 값이다. 의미 토큰화는 후속(대시보드/관심 종목 라운드와 동일 이월 항목).

## Questions

- "총 시그널" 등 정적 자리표시를 이번 PR에서 동적화(실제 카운트 파생/비활성 표기)할지, 아니면 실데이터
  연동 시 일괄 처리할지 — 관심 종목 PR #38은 리뷰 반영으로 동적화한 선례 있음.

  `Signal`에 둘지, 페이지 파생으로 유지할지.
