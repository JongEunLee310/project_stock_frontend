# PR #94 — 대시보드 미니차트 추이 연동 (feat/dashboard-trends-wiring)

리뷰어: Claude Code (Opus, 오케스트레이터). 구현: Codex. 브랜치: feat/dashboard-trends-wiring → main. 관련: FE #89, 설계 77, Pair BE 062(PR #156).

## Review Summary

설계 77대로 `src/pages/ui/DashboardPage.tsx`의 Today Brief 카드 미니 시각요소 중 하드코딩 장식 데이터를 BE 추이 시계열 API(`GET /dashboard/trends`)로 전환했습니다. 모듈 레벨 상수 `briefSparklineData`·`importantNewsBarData`를 제거하고, 기존 `src/features/dashboard/` 슬라이스를 확장(dto·adapter·query)해 `useDashboardTrends`를 추가했습니다.

`useDashboardTrends()`는 `GET /dashboard/trends`를 단일 호출하고(days 파라미터 없이 BE 기본 14일), envelope `data`를 `adaptDashboardTrends`로 도메인 `DashboardTrends { riskAlerts, reviewSignals, importantNews }`에 매핑합니다. adapter는 계열을 `key`(`risk_alerts`·`review_signals`·`important_news`)로 조회해 순서에 의존하지 않고, 결측 key는 빈 배열로 방어합니다. `count`는 int로 직렬화되므로 `parseDecimal` 없이 그대로 보존합니다.

설계의 결정이 모두 반영됐습니다: (1) 기존 dashboard 슬라이스 확장(신규 슬라이스 미생성), (2) dto snake_case·count int 보존, (3) `DashboardTrends` 도메인·`shared/model` 배치, (4) key 기반 조회·결측 방어 adapter, (5) 단일 호출·`['dashboard','trends']` query, (6) 계열→visual 매핑(risk_alerts→spark-risk, review_signals→spark-signal, important_news→bars-news), (7) 시각요소 슬롯 레벨 degradation.

## Blocking

None.

## Suggestions

**S1 · trends 실패 시 시각요소 무음 소거(비차단, 의도된 설계)**

trends 쿼리가 에러이거나 계열이 비면 미니 시각요소를 조용히 렌더하지 않습니다. 미니차트는 카드의 장식 accent이고 숫자 지표(summary)가 주 콘텐츠라는 설계 원칙(§4)에 따른 의도된 degradation으로, 카드 전체를 에러 상태로 승격시키지 않아 지표 가독성을 지킵니다. 다만 사용자에게 "추이 일시 미표시"를 알리는 신호는 없으므로, 향후 필요 시 슬롯에 옅은 placeholder를 둘 여지가 있습니다. 현 단계 비차단입니다.
