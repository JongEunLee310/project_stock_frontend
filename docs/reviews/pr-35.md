# PR #35 Local Review — Decision Log(판단 기록) 페이지 (task-013 / 이슈 11)

## Review Summary

`DecisionLogPage`를 플레이스홀더에서 시안 기반 실제 화면으로 교체. KPI 요약 카드 4, 판단 기록 로그
테이블(공통 `Table<DecisionLog>`), 새 판단 기록 폼(로컬 추가), 자주 나온 판단 패턴(CSS 막대), 최근 복기
메모를 구성했다. 시안의 판단유형·결과·인지 리스크를 담도록 도메인·Mock을 확장(Part A)하고 그 위에
페이지를 구현(Part B)했다. 설계 `docs/designs/11-decision-log-page.md`, 핸드오프
`.codex/tasks/task-013-decision-log-page.md`와 구조가 일치한다.

검토 항목:

- **확정 결정 준수(enum 교체)**: `decisionType.ts`가 시안 5값(관망 유지/추가 리서치 필요/매수 검토/
  비중 축소 검토/리스크 증가 검토)으로 재정의됨(기존 매수/비중 확대/관망/… 6값 폐기). 신규 enum
  `DecisionOutcome`(진행 중/대기/리서치 중)·`CognitiveRisk`(9종)은 `as const` + 파생 union 패턴
  (`stockStatus.ts` 선례). `DecisionLog`는 `outcome` 추가 + `cognitiveRisks: string[]→CognitiveRisk[]`로
  설계 표와 일치.
- **Badge 토큰 재사용(보호 파일 무변경)**: `Badge`에 `decisionType` 오버로드를 추가하되
  `decisionTypeClassNames`가 **기존 `status-*` @theme 토큰을 재사용**(관망 유지→watch-hold, 추가 리서치→
  research, 매수 검토→buy, 비중 축소→reduce, 리스크 증가→risk). **`src/index.css` 변경 없음**(신규 토큰 0).
  기존 status/riskLevel/tone 오버로드는 `never` 가드로 그대로 유지(하위 호환). 결과·인지 리스크 태그는
  기존 `tone`(info/neutral/warning)으로 표현.
- **파괴적 변경 회피**: 필수 필드 추가·필드 타입 변경에도 `mockDecisionLogs`(13건)·`mockDecisionPatterns`
  (5종)·`mockReviewMemos`를 전수 재작성하고 `satisfies` 유지 → `typecheck` 통과. `domain.test.ts`는
  `decisionType`/`cognitiveRisks`/`outcome`을 enum 멤버십까지 검증하도록 강화됨.
- **공통 컴포넌트 재사용**: 로그 테이블은 공통 `Table<DecisionLog>`(task-006) 컬럼·페이지네이션
  (pageSize 10)·`emptyMessage`로 구성. 종목은 `/research/:symbol` `Link`(행 네비게이션과 분리 위해
  `stopPropagation`). 판단유형·결과·인지 리스크는 `Badge` 재사용(인라인 색상 복제 없음). 카드는 `Card`.
- **새 판단 기록 폼 = 로컬 추가(확정 결정)**: 제어 입력(`useState`), 종목 미입력 시 인앱 `role="alert"`
  안내(네이티브 다이얼로그 미사용). 저장 시 새 `DecisionLog` 생성해 목록 상단 prepend + 폼 리셋, 초기화는
  입력만 리셋. 영속화 없음(설계대로).
- **KPI·패턴 파생 집계**: KPI는 `logs`에서 파생(총 기록 수·최근 7일·관망 유지·리스크 증가 검토). 신규 요약
  타입 없음(Signals 선례). 패턴은 `mockDecisionPatterns` 내림차순 + 비율%(count/합) CSS 막대바
  (`role="meter"` + aria). 차트 라이브러리 미도입.
- **타임존 안전**: 두 시간 포매터 모두 `timeZone: 'Asia/Seoul'` 고정. 최근 7일 임계값은 `new Date()`(현재
  시각)가 아니라 **최신 로그 `createdAt` 기준**으로 계산 → 테스트가 시점·타임존에 독립. 테스트는
  종목/판단유형/결과/건수/비율 라벨로 단언(시간 문자열 단언 회피).

로컬 검증: `format:check`·`lint`·`typecheck`·`TZ=UTC pnpm test`(52/52, DecisionLogPage 6건 신규)·`build`
모두 통과. `App.test.tsx`는 `/decision-log` 제목을 단언하지 않아 변경 불필요.

## Suggestions

- **Select 공통화(이월·3곳째)**: 이번 폼의 판단유형 `<select>` + 필터 자리표시 `<select>`로 인라인 select
  스타일(`selectClassName`)이 또 등장했다. Watchlist·Signals와 합쳐 `shared/ui`에 공통 `Select` 승격이
  점점 타당하다(본 PR 차단 아님).
- **패턴 위젯과 로컬 추가의 정합**: 자주 나온 판단 패턴은 정적 `mockDecisionPatterns`(합 13) 기반이라 폼으로
  새 판단을 로컬 추가해도 패턴/비율은 갱신되지 않는다. 현 단계 설계 의도(패턴=누적 집계 스냅샷)에 부합하나,
  추후 로컬 추가까지 반영하려면 패턴도 `logs` 파생으로 통일할 수 있다.
- **자리표시 명확화(후속)**: 상단 필터(일별/기간) `<select disabled>`, "복기 보기" 링크(자기 라우트)는
  의도된 자리표시다. 실제 필터링·복기 상세는 후속에서 활성화.
