# PR #38 Local Review — 관심 종목 페이지 시안 충실화 재구현 (이슈 8)

## Review Summary

이슈 8 관심 종목 페이지를 시안(`watchlist.png`) 충실도 우선으로 재구현했다. 대시보드 라운드와 동일한
시안 충실화 기조로 미니 시각요소(`recharts`)·셸 톤(`cockpit-*` 토큰)을 맞추고, 행 인터랙션(즐겨찾기 토글·
케밥 메뉴·행 클릭/키보드 네비게이션)을 충실화했다. 설계 `docs/designs/8-watchlist-page.md`에 "시안 충실화
재결정" 섹션을 추가해 구현과 일치시켰다.

검토 항목:

- **미니 시각요소 `recharts` 도입(이전 "이슈 19로 분리" 부분 뒤집음)**: 변화율 스파크라인(LineChart),
  요약 카드 막대(BarChart)·도넛(PieChart). 컴팩트 차트는 명시 `width`/`height`로 jsdom 경고 회피,
  `isAnimationActive={false}`로 결정성 유지. 데코 시각요소는 `aria-hidden`, 의미 차트는 `role="img"` +
  `aria-label`. 대시보드(PR #37)의 `recharts` 채택과 라이브러리 사용을 통일. 이슈 19 경계는 캔들·거래량 등
  본격 분석 차트 기준으로 재정의(대시보드 라운드와 동일).
- **타임존 안전**: 시간 포매터 `timeZone: 'Asia/Seoul'` 고정. 정렬 기본값은 `custom`(mock 원순서)이고 다른
  정렬 키도 고정 mock 값 기준이라 현재 시각 비의존. 테스트는 `/09:21/` 등 KST 환산 결과로 단언(`TZ=UTC`에서
  동일). `mockStocks.lastUpdatedAt`이 `00:21Z` → KST 09:21로 일관.
- **`mockStocks` 대시보드 공유 변경 — 회귀 확인**: 6종 확장(AMZN/GOOGL)·`aiVerdict` 한국어 라벨화·등락/
  `changeSeries`/`lastUpdatedAt` 갱신. 대시보드는 `mockStocks.slice(0,4)` + `dashboardStatusBySymbol`
  상태 오버라이드를 쓰고 `aiVerdict`는 표시하지 않아 영향 없음. 전체 테스트 58/58 유지로 회귀 없음 확인.
- **공통 컴포넌트 재사용**: 상태/위험도 `Badge`, `Card`/`Button`/`Input` 재사용. 종목 링크 `/research/:symbol`.
  케밥 메뉴는 네이티브 다이얼로그 없이 인앱 메뉴(`role="menu"`/`menuitem`)로 구현(규칙 준수).

## Suggestions

- **공통 `Table<T>` 미사용 — 페이지 로컬 `<table>` 직접 구성**: 즐겨찾기 토글 컬럼·행 케밥 메뉴·행 전체
  클릭/키보드 네비게이션·심볼별 브랜드 마크 등 시안 행 인터랙션을 위해 공통 `Table`을 버리고 직접 `<table>`을
  구성했다. 설계 문서에 의도적 결정으로 명시했으나, **공통 컴포넌트 우선 원칙에서 벗어나는 변경**이다. 추후
  다른 페이지에서도 동일 행 인터랙션 신호가 보이면 공통 `Table`에 행 액션/리딩 컬럼 슬롯을 확장해 재흡수할지
  검토 권장(본 PR 차단 아님 — 질문 참조).
- **잔여 `app-*` 토큰(케밥 메뉴·flat tone)**: 페이지 대부분은 `cockpit-*`로 통일했으나 `RowMenu`(트리거·
  드롭다운·메뉴 항목)와 `summaryToneClassNames.flat`이 여전히 `app-*` 토큰을 쓴다. 셸/페이지 톤 일관성을 위해
  `cockpit-*`로 통일 권장(비차단).
- **정적 자리표시 불일치**: 푸터 "전체 28개 중 1-6 표시"는 하드코딩이고 실제 로드 종목은 6종(`pageSize` 10).
  페이지네이션 1-5·표시 개수 셀렉트(10 고정)·열 설정·내보내기·전체화면도 동작 없는 자리표시다. 후속에서 실제
  카운트/동작 연동 시 표기 일치 필요.
- **원시 색/리터럴 토큰화(이월)**: 등락 emerald/rose, 브랜드 마크 hex(`#76b900` 등), 강조 blue/cyan/red,
  차트 stroke/fill hex가 원시값이다. 의미 토큰화는 후속(대시보드 라운드와 동일 이월 항목).

## 리뷰 반영 (Codex, 커밋 38d1e95)

- **잔여 `app-*` 토큰 통일**: 위 Suggestion 2를 반영. `RowMenu`(트리거·드롭다운·메뉴 항목)와
  `summaryToneClassNames.flat`의 `app-*` 토큰을 모두 `cockpit-*`로 교체. 페이지 `app-*` 사용 0 확인.
- **정적 자리표시 동적화**: 위 Suggestion 3을 반영. 푸터 "전체 N개 중 X-Y 표시"를 `visibleStocks.length`·
  표시 행 기반으로 동적 계산, 페이지 번호도 실제 페이지 수(`Math.ceil(length/pageSize)`, 최대 5)로 산출.
  동작 없는 컨트롤(열 설정·내보내기·전체화면·표시 개수 셀렉트·비활성 페이지·다음)에는 `disabled` 부여로
  자리표시임을 명확화.
- **미반영(설계 결정으로 유지)**: 공통 `Table` 미사용(Suggestion 1·Question)은 행 인터랙션 충실화를 위한
  의도적 결정으로 유지 — 패턴 확정은 다른 표 요구를 보고 후속 판단. 색/hex 토큰화는 이월(비차단).
- 재검증: `format:check`·`lint`·`typecheck`·`TZ=UTC test`(58/58)·`build` 전부 통과.
