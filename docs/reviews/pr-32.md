## Blocking

- **타임존 의존 테스트 실패 (CI)**: `WatchlistPage.test.tsx`의 "renders extended table columns and
  stock cells"가 `/09:21/`을 단언한다. mock `lastUpdatedAt`은 `2026-06-22T00:21:00.000Z`(UTC)이고
  `timeFormatter = new Intl.DateTimeFormat('ko-KR', { ... })`에 **`timeZone`이 없어 런타임 로컬존으로
  렌더**된다. 로컬(KST=UTC+9)은 09:21로 통과하지만 CI(UTC)는 00:21이라 실패.
  - **권장 수정**: 표시를 결정적으로 만들도록 `timeFormatter`에 `timeZone: 'Asia/Seoul'` 고정(한국어
    제품이므로 KST 표시가 자연스럽고 테스트 `/09:21/`도 유지됨). 또는 UTC 고정 + 테스트 기대값을
    `/00:21/`로 변경. 전자 권장.
  - 시간 표시가 환경 의존이면 다른 타임스탬프(마지막 갱신·추가 시각)도 동일 리스크 → 포매터 한 곳에
    `timeZone` 고정으로 일괄 해결.

## Suggestions

- **행 메뉴 외부 클릭 닫힘 부재**: `openMenuSymbol`은 토글로만 닫힌다. 다른 곳 클릭·ESC로 닫히지
  않아 여러 행 메뉴 UX가 거칠 수 있다. 후속에서 외부 클릭/ESC 닫힘 또는 공통 Dropdown 컴포넌트로
  승격 시 처리 권장(본 PR 차단 아님).
- **밸류에이션 셀이 Badge 스타일 인라인 복제**: `Badge`가 status/riskLevel만 지원해 밸류에이션은
  동일 클래스를 손으로 재현했다. `Badge`에 중립(neutral) 톤 또는 `ValuationLevel` 매핑을 추가해
  재사용하면 중복이 준다(컨벤션의 union 매핑 확장).
- **필터 Select 공통화 시점**: 정렬/방향/시장/위험 4개 네이티브 `<select>`가 반복된다. 다른 페이지
  (Signals 등)에서 재등장하면 `shared/ui` 공통 Select로 승격 권장(재사용 2곳 기준).
- **변화율 색상 토큰**: `emerald-300`/`rose-300` 직접 사용. 상승/하락 의미색 토큰이 생기면 치환 고려.
