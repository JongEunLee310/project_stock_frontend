**고정폭 grid 정렬**: `RiskPanel` 행은
`grid-cols-[0.5rem_minmax(0,9rem)_auto_minmax(0,1fr)]`이고, 제목 열은
`truncate`+`title`, 설명 열은 `min-w-0 truncate`+`title`이 적용되어
있습니다. 두 가변 트랙 모두 `minmax(0, ...)`이라 md 2열 좁은 폭에서도
텍스트가 잘릴 뿐 오버플로나 배지 겹침은 발생하지 않습니다.
`CoverageAxisRow`는 `grid-cols-[5.5rem_auto_minmax(0,1fr)]`인데, 첫
열(`axisLabel`)은 `minmax`가 아닌 고정 `5.5rem`이면서 span에
`truncate`나 `min-w-0`가 없습니다. 현재 매핑
(`researchCoverageAxisLabels`, `adapters.ts` 448행)의 알려진 5개 축
라벨(뉴스·가격·실적·밸류에이션·공시, 최대 5자)은 5.5rem 안에 들어가
문제가 없지만, 같은 어댑터의 폴백 경로(`researchCoverageAxisLabels[item.axis] ?? item.axis`,
532행)는 매핑에 없는 백엔드 enum 원문을 그대로 라벨로 씁니다.
`adapters.test.ts` 898행에 이미 `'ALTERNATIVE_DATA'`(17자) 폴백
케이스가 존재하는데, 이 값이 실제로 `CoverageAxisRow`에 렌더링되면
고정 5.5rem 열을 넘어 배지 열로 시각적으로 흘러넘칠 수 있습니다.
Suggestions에 기록합니다.

**체크리스트**: `<li>` 안에서 `<label>`과 `<InfoTooltip>`이 형제
요소로 분리되어 있고(1148행 부근), `InfoTooltip`이 `label` 내부에
중첩되지 않으므로 설명 버튼 클릭이 체크박스 토글을 오발동시키지
않습니다. 새 테스트

`fireEvent.focus/blur`로 툴팁 노출을 확인한 뒤 별도로 라벨 텍스트를

실제로 보증합니다.

**카테고리 톤 매핑**: `categoryToneClassNames`는 카테고리별로 완성된
Tailwind 클래스 문자열을 정적으로 나열합니다(동적 템플릿 보간 없음)
— Tailwind purge에 안전합니다. `getCategoryToneClassNames`는
`label ?? '미지정'`로 null/undefined를, 이어지는
`?? categoryToneClassNames.미지정`로 매핑에 없는 빈 문자열이나
미등록 라벨(`'미분류 항목'` 등)을 모두 neutral로 폴백시킵니다.
타임라인 점(`timelineDot`, `border-{c}-400` 계열)과 배지

색상군을 공유해 두 시각 요소의 카테고리 색이 일치합니다.
`Badge tone="neutral" className={...override}` 패턴은 이번 PR이
처음 도입한 것이 아니라 같은 파일의 기존 `sentimentClassNames`
사용처(1244행)와 동일한 확립된 패턴이라 새로운 리스크로 보지
않습니다.

**테스트 실질성**: 행 순서·체크리스트 토글/툴팁·카테고리 색 매핑

## Suggestions

`CoverageAxisRow`(`src/pages/ui/ResearchPage.tsx` 1076행 부근)의
`axisLabel` span에 `RiskPanel`의 제목 열과 동일한 `truncate`+
`min-w-0`(또는 `minmax(0, 5.5rem)`) 보호가 없습니다. 현재 알려진 5개
축 라벨은 문제없이 들어가지만, `adapters.ts`의 미매핑 폴백 경로가
백엔드 enum 원문(예: 테스트 픽스처의 `'ALTERNATIVE_DATA'`)을 그대로
노출할 수 있어, 향후 새 커버리지 축이 추가되고 프런트 매핑이 아직
갱신되지 않은 과도기에 라벨이 배지 열로 흘러넘칠 가능성이 있습니다.
백엔드가 새 축을 실제로 내려보내는 시점까지는 발생하지 않으므로
이번 PR 범위에서 blocking으로 보지는 않으며, 후속 PR에서
`truncate`+`title` 한 줄을 추가하는 정도로 가볍게 해소할 수 있습니다.

설계 문서 범위와 diff가 정확히 일치하고, 신호등 색 토큰은 WCAG AA

diff와 테스트로 직접 확인했습니다. 카테고리 톤 매핑은 purge에

처리하며, 기존 `sentimentClassNames`와 동일한 확립된 오버라이드
패턴을 따릅니다. 유일하게 짚어둔 항목은 `CoverageAxisRow`의 고정폭
라벨 열이 미매핑 폴백 라벨에 대해 `truncate` 보호가 없다는 점인데,
