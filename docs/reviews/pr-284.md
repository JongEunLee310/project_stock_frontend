# PR #284 로컬 리뷰 — 종목별 뉴스·공시 페이지를 이벤트 중심 피드로 재구성 (#201)

## Review Summary

PR #195의 임시 `ResearchNewsPage`(뉴스/공시 탭 + `/assets/{id}/news-disclosure`)를 새 설계의 이벤트 중심 피드로 재구성한 PR입니다. 단일 커밋(`종목별 뉴스 피드를 이벤트 중심으로 재구성`)이며, 이 PR로 에픽 #198의 미구현 화면이 없어집니다.

`useNewsEventsQuery`를 옵션 파라미터(`{ symbols }: NewsEventsQueryParams = {}`)로 확장했습니다. `symbols`는 `searchParams.append`로 반복 쿼리 파라미터(`symbols=X`)로 직렬화되어 BE의 `list[str]` 계약과 맞고, queryKey에 포함되어 시장 전체 피드와 종목별 피드가 캐시상 분리됩니다. 기본 인자 덕분에 개요의 `useNewsEventsQuery()` 호출부는 수정 없이 그대로 동작합니다.

개요 피드 위젯 `RealtimeEventFeed`를 공유 가능하게 확장했습니다. `title`·`description`·`showSymbolColumn` 옵션 props를 추가하되 기본값을 현재 개요 문구와 컬럼 구성으로 두어 개요 회귀가 없고, 컬럼 정의를 `documentTypeColumn`·`symbolColumn`·`eventDetailColumns`로 분해해 `showSymbolColumn`에 따라 조립합니다. 이벤트 상세(#204)가 정착했으므로 제목 셀을 `generatePath(appRoutePaths.newsEventDetail, { eventId })` **Link**로 전환했습니다 — 셀 전체 onClick이 아니라 링크라 키보드 접근과 포커스 링이 확보되고, 두 피드가 동일하게 동작합니다.

`ResearchNewsPage`는 탭·`useAssetIdBySymbol`·`useNewsDisclosure` 의존을 걷어내고 `SymbolNewsFeed`가 `useNewsEventsQuery({ symbols: [symbol] })`로 종목 한정 피드를 렌더합니다. 종목 컬럼은 숨기고(모든 행이 같은 종목) 종목별 제목·설명을 넘기며, 리서치 상세로 돌아가는 링크와 라우트(`/research/:symbol/news`)는 유지됩니다. 심볼이 없으면 EmptyState로 안내합니다.

이번 리뷰는 개요 피드 회귀 여부, 공유 컴포넌트의 기본값 보존, 링크 접근성, 보존 대상(`NewsDisclosureList`·`useNewsDisclosure`) 유지, 신선도·cursor 동작 유지를 축으로 봤습니다.

## Blocking

None.

## Suggestions

**S1. 종목별 피드에도 종목 컬럼 대신 심볼이 헤더에만 노출 — 의도된 선택.** `showSymbolColumn={false}`로 종목 컬럼을 숨기고 제목·설명에 심볼을 넣었습니다. 모든 행이 동일 종목이므로 반복 컬럼을 없앤 판단이 타당하고, 화면 폭을 이벤트 요약에 더 줍니다. 다만 BE가 향후 관련 종목을 함께 반환하는 형태로 넓어지면 컬럼 재노출을 검토할 여지가 있습니다.

**S2. 기존 `/assets/{id}/news-disclosure` 경로는 리서치 상세에만 남음 — 계약 이원화 인지.** 이 페이지가 news-insights 계약으로 옮겨가면서, 같은 성격의 데이터를 리서치 상세 카드(`NewsDisclosureList`)는 여전히 구 계약으로 읽습니다. 이번 이슈 범위가 임시 페이지 교체로 한정돼 있어 정상이지만, 리서치 상세 카드까지 news-insights로 통일하는 후속을 별도로 다루면 계약이 하나로 모입니다.

## Questions

**Q1. 보존 대상이 실제로 온전한가.** `NewsDisclosureList` 위젯·`useNewsDisclosure` query·`ResearchPage`가 변경되지 않았는지 diff로 확인했습니다. 변경 파일은 features(queries·index)·`RealtimeEventFeed`·`ResearchNewsPage`와 각 테스트뿐이며, 보존 대상 3종은 diff에 없습니다. 리서치 상세 카드 동작에 영향이 없습니다.

## Final Recommendation

머지 가능합니다. 핸드오프 요구사항을 항목별로 확인했습니다. 개요와 종목별 페이지가 같은 행 컴포넌트를 쓰고(스타일 중복 정의 없음), 옵션 props 기본값이 개요의 기존 제목·설명·컬럼을 그대로 유지하며, 제목 셀 링크가 `/news/events/:eventId`를 가리키고 키보드로 접근 가능합니다. cursor 더 보기·부분 실패·빈 상태·데이터 신선도(#266) 동작이 유지되고, 심볼 부재 시 안내가 있습니다.

범위는 지켜졌습니다. `NewsDisclosureList`·`useNewsDisclosure`·`ResearchPage`는 변경되지 않았고 필터 UI 추가나 BE 계약 변경도 없습니다. Protected Files는 없으며 신규 npm 의존성 추가도 없습니다. 추가·갱신된 테스트는 symbols 유무에 따른 요청 URL과 queryKey 구분, `showSymbolColumn` 동작과 제목 링크 대상, 종목별 페이지의 렌더·로딩·오류·빈 상태, 개요 페이지 회귀를 덮습니다.

Blocking은 없습니다. S1·S2는 설계 선택·후속 통일 사항으로 병합을 막지 않으며, Q1은 보존 대상이 diff에 없음을 확인해 해소했습니다.
