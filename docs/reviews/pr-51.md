# PR #51 Local Review — 어댑터 계층 순수 변환 프리미티브 (이슈 #45)

## Review Summary

이슈 #45. ADR-004(서버상태·API client·어댑터) 게이트 통과 후, 어댑터 계층의 **순수·동기 변환
프리미티브**를 추가했다. 설계 `docs/designs/45-adapter-layer.md`와 일치한다. `API 계약 정렬 — 프론트엔드`
마일스톤. 파이프라인: Opus 설계 → Sonnet 구현 → Opus 검증·PR.

검토 항목:

- **envelope 언랩(C1·C9)**: `unwrapEnvelope`가 `error` truthy면 `ApiError`(code 보유) throw, 아니면
  `{ data, meta }`만 반환. 화면·쿼리 함수가 envelope를 직접 보지 않는 단일 경계. `errorCodes`로
  `code`→한글 메시지 매핑 + 미지 코드 fallback.
- **파싱·표시(C5)**: `parseDecimal`은 null/빈문자/NaN을 안전하게 `null`로. `formatMoney`(`Intl`),
  `formatPercent`(0~1 비율 입력 가정, 주석·테스트로 고정).
- **시간(C6)**: `formatKstDate`/`formatKstDateTime`이 timeZone `Asia/Seoul` 하드코딩. `TZ=UTC`에서
  KST 변환 단언(예: `15:00Z`→다음날 KST). [[verify-timezone-tz-utc]] 준수.
- **enum 한글화(C8)**: 제네릭 `toLabel(map, wire, fallback)` + `riskLevelLabels`(HIGH/MEDIUM/LOW)·
  `alertStatusLabels`. StockStatus/ValuationLevel 와이어 영문값은 계약 미확정이라 #47로 분리(설계 일치).
- **서버 페이징(C2·C7)**: `Table`에 `manual` 플래그 추가 — true면 내부 `rows.slice`를 건너뛰고 받은
  rows를 그대로 렌더(서버가 현재 페이지 행만 반환). `toTablePagination(meta)`는 `manual:true`로 매핑.
  `buildSortParam`은 `field`/`-field` 직렬화.
- **스코프 통제**: 네트워크(fetch client·인증·401)·도메인 모델 교체·화면 연동은 손대지 않음(#46/#47/#48).
  신규 라이브러리 없음(순수 TS + `Intl`).

## Blocking

- 없음.

## Suggestions

- **서버 에러 메시지 활용(비차단, #46 연동 시)**: `unwrapEnvelope`가 `env.error.message`(서버 제공)를
  버리고 `code` 매핑 메시지만 쓴다. 실제 에러가 흐르는 #46에서 서버 메시지가 디테일을 담을 수 있으므로
  `messageForErrorCode(code, env.error.message)` 형태의 fallback 우선순위를 검토 권장.
- **`Table` manual 모드 하위호환(확인됨)**: `manual` 미지정 시 기존 클라이언트 슬라이싱 동작 유지.
  기존 `Table.test.tsx`·호출부(Dashboard/DecisionLog 등) 회귀 없음(117 통과).
